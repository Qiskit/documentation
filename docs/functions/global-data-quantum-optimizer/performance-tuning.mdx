# Advanced techniques with Global Data Quantum Portfolio Optimizer

Use the following techniques to get the most out of the Quantum Portfolio Optimizer. For every parameter and its default value, see the [API reference](/docs/api/functions/global-data-quantum-optimizer).

## Choose an ansatz

Set `ansatz` in `ansatz_settings` to `real_amplitudes` (default), `cyclic`, `optimized_real_amplitudes`, or `tailored`. The `tailored` ansatz is available only for `ibm_torino` with 7 assets, 4 time steps, and 4 resolution qubits. The `optimized_real_amplitudes` ansatz usually optimizes better than `real_amplitudes`, but it needs more circuit executions, so it is most useful for problems with up to about 100 qubits.

To compare several pass managers and keep the one with the lowest estimated cumulative error, set `multiple_passmanager=True` (not available for the `tailored` ansatz). To add dynamical decoupling, set `dd_enable=True`.

## Size the optimizer

In `optimizer_options`, `population_size` and `num_generations` set the total number of circuits: `(num_generations + 1) * population_size`. For the `real_amplitudes` ansatz, use a minimum `population_size` of about `0.8 * n_qubits`. Avoid a population size above 120 or more than 20 generations. Use `max_parallel_jobs` and `max_batchsize` to control how many QPU jobs run in parallel and how large each batch is.

## Set primitive options

In `primitive_options`, set `sampler_shots` and `estimator_shots`, or set `estimator_precision` to use a target precision instead of a fixed number of Estimator shots. Use `max_time` to limit how long the runtime session stays open. Keep within the [job limits](/docs/guides/job-limits).

## Resume a run

To resume an optimization or add generations, pass the same inputs with the earlier session IDs in `previous_session_id`, and increase `num_generations` if needed. Loading previous sessions can take up to one hour of classical time, but does not use quantum runtime.

## Tag and post-process

Use `tags` to label your experiments. Set `apply_postprocess=False` to skip the noise-aware SQD post-processing, which is on by default.
