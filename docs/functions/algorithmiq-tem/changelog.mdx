# Algorithmiq TEM changelog

- 16 September 2024: TEM is available in the [Qiskit Functions Catalog](https://quantum.cloud.ibm.com/functions) as a circuit function. It applies tensor-network error mitigation, an error mitigation method for obtaining estimators with fewer shots than the probabilistic error cancellation (PEC) method.
