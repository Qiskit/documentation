## Install the client package

Install the `qiskit-ibm-catalog` package:

```bash
pip install qiskit-ibm-catalog
```

This command also installs `qiskit-serverless`, `qiskit`, and `qiskit-ibm-runtime` as dependencies. You do not need to install `qiskit-serverless` separately.

The two packages have different roles:

- `qiskit-ibm-catalog` is the client that you use in your local Python session to upload workflows, run them, and get their results.
- `qiskit-serverless` is used inside your workflow code, with helpers for `get_arguments()`, `update_status()`, `save_result()`.

### Update the client package

Managed workflows is in beta, and the client package changes often. To check which version you have, run the following command:

```bash
pip show qiskit-ibm-catalog
```

To update to the latest version, run the following command:

```bash
pip install --upgrade qiskit-ibm-catalog
```

If the new version of `qiskit-ibm-catalog` requires a newer version of `qiskit-serverless`, this command updates `qiskit-serverless` too.

## Authenticate

<Admonition type="danger" title="Protect your API key">
Do not include your API key in your workflow code, in scripts, or in notebook files. A running workflow uses the credentials and instance that you used to call `run()`.
</Admonition>

The managed workflows client uses the same credentials as `qiskit-ibm-runtime`. If you already saved an account with `QiskitRuntimeService.save_account()`, the client loads your default saved account, and you can skip to [Verify your setup](#verify-your-setup).

If you have not saved an account, save your API key and instance CRN one time in a trusted environment:

{/* REVIEW: class rename pending */}
```python
from qiskit_ibm_catalog import QiskitServerless

QiskitServerless.save_account(
    token="<your-api-key>",
    instance="<your-instance-crn>",
)
```

This method writes your credentials to the same file as [`QiskitRuntimeService.save_account()`](/docs/api/qiskit-ibm-runtime/qiskit-runtime-service#save_account). The client uses the `ibm_quantum_platform` channel by default, so you do not need to set `channel`. To save more than one account, set `name`, and pass the same `name` when you create the client.

For more options, such as saving several accounts or selecting an instance automatically, see [Save your login credentials](/docs/ibm-quantum-platform/save-credentials). If you work on a public computer or another untrusted environment, do not save your credentials. Instead, follow [Initialize the service in an untrusted environment](/docs/ibm-quantum-platform/cloud-setup-untrusted).

## Verify your setup

Connect to managed workflows with your saved account, and list the workflows that you uploaded:

{/* REVIEW: class rename pending. list() is renamed to functions() in qiskit-ibm-catalog PR #139. */}
```python
from qiskit_ibm_catalog import QiskitServerless

serverless = QiskitServerless()
serverless.list()
```
