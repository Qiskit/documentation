# Circuit Functions

Circuit Functions simplify the execution of quantum circuits by abstracting away key steps such as transpilation, error suppression, and error mitigation. They allow researchers using Qiskit to focus on developing and evaluating quantum algorithms without having to manage all the complexities of optimizing circuits for quantum hardware. Circuit Functions typically accept circuit-oriented inputs, such as PUB (Primitive Unified Bloc) objects, and return results such as mitigated expectation values. They can also serve as building blocks for creating higher-level, customized quantum applications.

<Admonition type="note" title="Notes">
IBM Quantum Functions are an experimental feature available only to IBM Quantum&reg; Premium Plan, Flex Plan, and On-Prem (via IBM Quantum Platform API) Plan users. Refer to [Set up IBM Quantum Functions](/docs/ibm-quantum-platform/functions-get-started.ipynb) for instructions on getting access.
</Admonition>
