# Noise Modeling

A noise model describes how errors affect the results from executing a quantum circuit. Noise models support several stages of a typical workflow including: simulating a circuit classically to estimate expected performance before submitting a job  or to inform an error-mitigation technique such as probabilistic error cancellation. For general strategies to reduce the impact of noise during execution, see [Overview of noise management techniques](/docs/guides/error-mitigation-and-suppression-techniques).

This page collects the packages and capabilities that support each part of that workflow, grouped into learning noise from a device, building a noise model for classical simulation, and refining a noise model for a specific error-mitigation technique.

## Building and running noise learning algorithms

Use noise learning packages to characterize a device's noise directly from experimental data. These packages run randomized circuits to estimate error rates and build a noise model that reflects actual hardware behavior.
