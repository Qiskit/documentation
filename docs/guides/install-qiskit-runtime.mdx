# Install the Qiskit Runtime client

The IBM Quantum Compute Service is the cloud-based service for executing quantum computations on IBM Quantum&reg; hardware. This guide shows you how to install `qiskit-ibm-runtime`, which is the client package for accessing the IBM Quantum Compute Service.

Before installing the `qiskit-ibm-runtime`, follow the instructions in these guides:

1. [Install Qiskit](/docs/guides/install-qiskit). 
2. [Set up your IBM Cloud account](cloud-setup).

Run this command to install the Qiskit Runtime client:

```shell
pip install qiskit-ibm-runtime
```

<Admonition type="note" title="Stay current with the latest versions">
    Periodically check the [`qiskit-ibm-runtime` release notes](/docs/api/qiskit-ibm-runtime/release-notes) to see new releases. We recommend frequently updating your requirements for `qiskit-ibm-runtime` by running `pip install -U qiskit-ibm-runtime`.
</Admonition>
