# Qiskit AI skills 

The [Qiskit AI skills repository](https://github.com/Qiskit/skills) has a set of skills that you can use with AI assistants, such as Bob, Claude, or ChatGPT. An AI skill is a reusable set of instructions that teaches the assistant how to complete a specific task.  Skills can help save time and ensure that repeatable tasks are done consistently and correctly.  

The first available skill is `migrate-qiskit-ibm-runtime`, for migrating `qiskit-ibm-runtime` code.

To use a Qiskit AI skill, follow the instructions for your AI assistant.  In general, you just need to give the skill to the assistant, then tell it where to apply the skill.
