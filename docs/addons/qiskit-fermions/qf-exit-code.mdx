# QfExitCode

<Class id="c.QfExitCode" isDedicatedPage={true} signature="enum QfExitCode">
  Integer exit codes returned to C.

  *Values:*

  ### enumerator QfExitCode\_Success

  <Attribute id="c.QfExitCode.QfExitCode_Success">
    `0`: Success.
  </Attribute>

  ### enumerator QfExitCode\_CInputError

  <Attribute id="c.QfExitCode.QfExitCode_CInputError">
    `100`: Error related to data input.
  </Attribute>

  ### enumerator QfExitCode\_NullPointerError

  <Attribute id="c.QfExitCode.QfExitCode_NullPointerError">
    `101`: Unexpected null pointer.
  </Attribute>

  ### enumerator QfExitCode\_AlignmentError

  <Attribute id="c.QfExitCode.QfExitCode_AlignmentError">
    `102`: Pointer is not aligned to expected data.
  </Attribute>

  ### enumerator QfExitCode\_IndexError

  <Attribute id="c.QfExitCode.QfExitCode_IndexError">
    `103`: Index out of bounds.
  </Attribute>

  ### enumerator QfExitCode\_DuplicateIndexError

  <Attribute id="c.QfExitCode.QfExitCode_DuplicateIndexError">
    `104`: Duplicate index.
  </Attribute>

  ### enumerator QfExitCode\_ValueError

  <Attribute id="c.QfExitCode.QfExitCode_ValueError">
    `200`: Error related to some in- or output value. Refer to the function documentation for more details.
  </Attribute>
</Class>
