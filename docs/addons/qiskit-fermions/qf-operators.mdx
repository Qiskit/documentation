# Operator Representations

The C API provides various data structures for representing fermionic operators in different bases.

|                                                                             |                                                                                          |
| --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [`QfFermionOperator`](qf-ferm-op#c.QfFermionOperator "QfFermionOperator")   | An operator in the basis of the second-quantization creation and annihilation operators. |
| [`QfMajoranaOperator`](qf-maj-op#c.QfMajoranaOperator "QfMajoranaOperator") | An operator in the basis of Majorana fermions.                                           |
