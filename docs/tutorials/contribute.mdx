# Contribute a tutorial

Qiskit tutorials on IBM Quantum&reg; Platform are open to community contributions. This page explains which tutorials you can contribute, what each kind of tutorial must show, and how to propose one.

Every tutorial belongs to a domain: optimization, Hamiltonian simulation, quantum machine learning, or quantum information science. In the first three domains, each tutorial is either Foundational or Applied:

- **Foundational tutorials** teach the core ideas and canonical methods of a domain. They use well-known teaching problems, so that the method is the focus rather than the problem.
- **Applied tutorials** are built around a specific goal: solving a particular problem from the problem classes on this page, or applying a specialized technique or tool in the setting where it can be used successfully. They assume strong familiarity with the fundamentals.

In short, Foundational tutorials show how to use a method or tool, and Applied tutorials show the best current results on a specific problem.

Quantum information science tutorials teach general-purpose techniques that tutorials in every domain use, such as compilation and error mitigation. Instead of being Foundational or Applied, each one belongs to a [topic category](#quantum-information-science).

## What you can contribute

Every domain is open to contributions. Optimization, Hamiltonian simulation, and quantum machine learning are open to both Foundational and Applied tutorials:

| Domain | Foundational tutorials | Applied tutorials |
| --- | --- | --- |
| [Optimization](#optimization) | 1 problem class | 10 problem classes |
| [Hamiltonian simulation](#hamiltonian-simulation) | 3 problem classes | 8 problem classes |
| [Quantum machine learning](#quantum-machine-learning) | 3 problem classes | 5 problem classes |

[Quantum information science](#quantum-information-science) is open to tutorials in five topic categories, from building blocks to error correction.

## Requirements

Every tutorial must:

- Follow the tutorial template, use current Qiskit with no deprecated interfaces, and cover something that [IBM Quantum Learning](/learning) courses and existing tutorials do not.
- Use only the [approved quantum packages](#approved-quantum-packages), including Qiskit Functions, pin every package version, and keep custom code in the notebook.
- Verify a small instance against a known answer (exact, analytic, or published) within a stated tolerance before scaling up.
- Run on IBM Quantum hardware at about 50 qubits or more, and report the error mitigation settings and QPU time.

Beyond these, each kind of tutorial covers different ground and meets a different bar:

- **Foundational tutorials** teach how to use a method or tool on one of the domain's [foundational problem classes](#problem-classes), show its trade-offs against a default approach, and point readers to where the method leads next.
- **Applied tutorials** solve a real instance from a [problem class](#problem-classes). They compare against a classical method and meet a state-of-the-art bar.
- **Quantum information science tutorials** teach a technique from one of the [topic categories](#quantum-information-science), compare it against the category's default approach, and point readers to where the technique leads next.

For the detailed requirements and how reviewers check them, see the [guide to adding tutorials](https://github.com/Qiskit/documentation/blob/main/adding-tutorials.md).

## How to propose a tutorial

Contributions go through two stages, so that you get feedback before you write the full tutorial.

1. **Propose.** Open a [tutorial proposal issue](https://github.com/Qiskit/documentation/issues/new?template=tutorial-proposal.yaml) in the Qiskit documentation repository. The IBM Quantum tutorials team and a member of the relevant working group review it against these requirements.
2. **Submit.** After your proposal is approved, open a pull request from your fork that adds the notebook, and sign the [Contributor License Agreement](https://qisk.it/cla).

To improve an existing tutorial, propose the improvement the same way. The [guide to adding tutorials](https://github.com/Qiskit/documentation/blob/main/adding-tutorials.md) describes the review process and how to add your notebook.

## Authorship

- **Credit.** Your tutorial shows a byline with the authors' names and affiliations and a link to the source paper, and its tutorial card shows a community tag. This page also lists you as a community contributor for the tutorial's problem class or topic category.
- **Ongoing maintenance.** A maintainer of record from the IBM Quantum team keeps the tutorial running as Qiskit changes.
