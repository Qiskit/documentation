# Wire

`qiskit_paulice.wire`

Wires: the stretches of a qubit’s timeline between consecutive gates.

### Wire

<Class id="qiskit_paulice.wire.Wire" github="https://github.com/Qiskit/qiskit-paulice/tree/main/qiskit_paulice/wire.py#L21-L33" signature="Wire(qubit, after_instruction)" modifiers="class">
  Bases: [`NamedTuple`](https://docs.python.org/3/library/typing.html#typing.NamedTuple)

  A stretch of one qubit’s timeline between two consecutive gates on that qubit.

  Barriers and measurements are not gates, so they do not start or end a wire.

  #### qubit

  <Attribute id="qiskit_paulice.wire.Wire.qubit">

  </Attribute>

  #### after\_instruction

  <Attribute id="qiskit_paulice.wire.Wire.after_instruction">
    Index into `QuantumCircuit.data` of the gate on `qubit` that the wire follows. `None` denotes the qubit’s input wire, before its first gate.

    **Type**

    [int](https://docs.python.org/3/builtins/functions.html#int) | None
  </Attribute>

  Create new instance of Wire(qubit, after\_instruction)
