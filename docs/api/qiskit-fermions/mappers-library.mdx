# Mapper Library

This module provides efficient implementations of commonly used operator representation mapper routines.

## Python wrappers

The functions below are thin, type-agnostic convenience mappers. Each delegates to the appropriate library implementation below under the hood, based on the type of the object it is given. They do not implement any conversion logic themselves.

|                                                                                                                                                                                                       |                                                                                                                                                                                                  |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`fermion_operator`](/docs/api/qiskit-fermions/mappers-library-fermion-operator#qiskit_fermions.mappers.library.fermion_operator "qiskit_fermions.mappers.library.fermion_operator")(operator)        | Converts an operator into a [`FermionOperator`](/docs/api/qiskit-fermions/operators-fermion-operator#qiskit_fermions.operators.FermionOperator "qiskit_fermions.operators.FermionOperator").     |
| [`jordan_wigner`](/docs/api/qiskit-fermions/mappers-library-jordan-wigner#qiskit_fermions.mappers.library.jordan_wigner "qiskit_fermions.mappers.library.jordan_wigner")(operator, num\_qubits)       | Map an operator to a `SparseObservable` under the Jordan-Wigner transformation.                                                                                                                  |
| [`majorana_operator`](/docs/api/qiskit-fermions/mappers-library-majorana-operator#qiskit_fermions.mappers.library.majorana_operator "qiskit_fermions.mappers.library.majorana_operator")(operator)    | Converts an operator into a [`MajoranaOperator`](/docs/api/qiskit-fermions/operators-majorana-operator#qiskit_fermions.operators.MajoranaOperator "qiskit_fermions.operators.MajoranaOperator"). |

## Ternary-tree encodings

These map an operator through a ternary-tree encoding, which is built with [`TernaryTree`](/docs/api/qiskit-fermions/mappers-ternary-tree#qiskit_fermions.mappers.TernaryTree "qiskit_fermions.mappers.TernaryTree") and [`TernaryTreeEncoding`](/docs/api/qiskit-fermions/mappers-ternary-tree-encoding#qiskit_fermions.mappers.TernaryTreeEncoding "qiskit_fermions.mappers.TernaryTreeEncoding") from the [`mappers`](mappers#module-qiskit_fermions.mappers "qiskit_fermions.mappers") framework module. Compile a tree once and reuse the encoding across every operator mapped through it. The type-agnostic [`ternary_tree()`](/docs/api/qiskit-fermions/mappers-library-ternary-tree#qiskit_fermions.mappers.library.ternary_tree "qiskit_fermions.mappers.library.ternary_tree") wrapper dispatches to these.
