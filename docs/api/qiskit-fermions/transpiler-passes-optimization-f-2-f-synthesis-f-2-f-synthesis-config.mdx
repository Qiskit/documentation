# F2FSynthesisConfig

<Attribute id="qiskit_fermions.transpiler.passes.optimization.f2f_synthesis.F2FSynthesisConfig" isDedicatedPage={true}>
  The dictionary type used to configure the [`F2FSynthesis.methods`](transpiler-passes-f-2-f-synthesis#methods "qiskit_fermions.transpiler.passes.F2FSynthesis.methods").

  The keys of this dictionary must be names of [`FermionicGate`](circuit-fermionic-gate "qiskit_fermions.circuit.FermionicGate") classes that can be broken down in fermionic space. The values can be one of four types:

  1.  `str`: the simplest scenario simply specifies the name of the plugin method to use for the corresponding key in this dictionary. The plugin is extracted from the [`F2FSynthesisPluginManager`](circuit-library-synthesis-f-2-f-synthesis-plugin-manager "qiskit_fermions.circuit.library.synthesis.F2FSynthesisPluginManager") and its `__init__` method may **not** require any arguments.
  2.  `tuple[str, Sequence[Any]]`: the first `str` is the same as the above, and the second `Sequence[Any]` can be used to provide any positional arguments to the plugin’s `__init__` method.
  3.  `tuple[str, Sequence[Any], Mapping[str, Any]]`: the first two fields are the same as in 2. and the third `Mapping[str, Any]` can be used to provide any keyword arguments to the plugin’s `__init__` method.
  4.  an instance of an [`F2FSynthesisPlugin`](circuit-library-synthesis-f-2-f-synthesis-plugin "qiskit_fermions.circuit.library.synthesis.F2FSynthesisPlugin"), which is used as is. This is how a plugin that is not registered through an entry point enters the pass.
