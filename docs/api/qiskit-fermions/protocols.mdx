# Protocols

This module provides various protocols used throughout the package.

A [`typing.Protocol`](https://docs.python.org/3/library/typing.html#typing.Protocol) is an interface that a class can fulfill structurally, without explicitly inheriting from it. For example, any class that implements a `__len__` method satisfies [`Sized`](https://docs.python.org/3/library/typing.html#typing.Sized), whether or not it says so anywhere in its class hierarchy.

The protocols in this module follow the same idea, but each one centers on a single, otherwise unremarkable dunder-style method (for example `_majorana_operator_`). A class implementing that one method thereby satisfies the corresponding protocol ([`SupportsMajoranaOperator`](/docs/api/qiskit-fermions/protocols-supports-majorana-operator#qiskit_fermions.protocols.SupportsMajoranaOperator "qiskit_fermions.protocols.SupportsMajoranaOperator") in this example) and becomes usable wherever that protocol is expected, without any explicit registration. Note that “protocol” is sometimes also used loosely to refer to a type-agnostic dispatch function built on top of a protocol (for example [`fermion_operator()`](/docs/api/qiskit-fermions/mappers-library-fermion-operator#qiskit_fermions.mappers.library.fermion_operator "qiskit_fermions.mappers.library.fermion_operator")) rather than the interface itself; the distinction should be clear from context.

Some protocols below are paired with a small, type-agnostic **helper function** that dispatches to the protocol method on whatever object it is given.

## Protocols implemented from ffsim

Simulation is [ffsim](https://qiskit-community.github.io/ffsim/)’s concern, and its protocols are defined there rather than restated here. The gates and operators of this package implement the following, so ffsim’s dispatchers accept them directly:

| ffsim protocol                                                                                                                                                   | Method                                          | Implemented by                                                                                                                                                                                                                                                                                                            |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`ffsim.SupportsApplyUnitary`](https://qiskit-community.github.io/ffsim/api/stubs/ffsim.SupportsApplyUnitary.html#ffsim.SupportsApplyUnitary "(in ffsim)")       | `_apply_unitary_(self, vec, norb, nelec, copy)` | [`FermionicCircuit`](/docs/api/qiskit-fermions/circuit-fermionic-circuit#qiskit_fermions.circuit.FermionicCircuit "qiskit_fermions.circuit.FermionicCircuit") and every [`FermionicGate`](/docs/api/qiskit-fermions/circuit-fermionic-gate#qiskit_fermions.circuit.FermionicGate "qiskit_fermions.circuit.FermionicGate") |
| [`ffsim.SupportsLinearOperator`](https://qiskit-community.github.io/ffsim/api/stubs/ffsim.SupportsLinearOperator.html#ffsim.SupportsLinearOperator "(in ffsim)") | `_linear_operator_(self, norb, nelec)`          | [`FermionOperator`](/docs/api/qiskit-fermions/operators-fermion-operator#qiskit_fermions.operators.FermionOperator "qiskit_fermions.operators.FermionOperator")                                                                                                                                                           |

<Admonition title="Caution" type="note">
  [`ffsim.SupportsFermionOperator`](https://qiskit-community.github.io/ffsim/api/stubs/ffsim.SupportsFermionOperator.html#ffsim.SupportsFermionOperator "(in ffsim)") shares the `_fermion_operator_` method name with this package’s [`SupportsFermionOperator`](/docs/api/qiskit-fermions/protocols-supports-fermion-operator#qiskit_fermions.protocols.SupportsFermionOperator "qiskit_fermions.protocols.SupportsFermionOperator"), but the two are *not* the same contract: ours returns this package’s [`FermionOperator`](/docs/api/qiskit-fermions/operators-fermion-operator#qiskit_fermions.operators.FermionOperator "qiskit_fermions.operators.FermionOperator") rather than ffsim’s unrelated type. Since [`ffsim.fermion_operator()`](https://qiskit-community.github.io/ffsim/api/stubs/ffsim.fermion_operator.html#ffsim.fermion_operator "(in ffsim)") dispatches purely on the method name, calling it on an object of this package returns our type.
</Admonition>
