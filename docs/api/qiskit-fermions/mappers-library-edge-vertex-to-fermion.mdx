# edge\_vertex\_to\_fermion

<Function id="qiskit_fermions.mappers.library.edge_vertex_to_fermion" isDedicatedPage={true} signature="edge_vertex_to_fermion(inter_op)">
  Map an [`EdgeVertexOperator`](operators-edge-vertex-operator "qiskit_fermions.operators.EdgeVertexOperator") to a [`FermionOperator`](operators-fermion-operator "qiskit_fermions.operators.FermionOperator").

  **Parameters**

  **inter\_op** – the edge-vertex operator to map.

  **Returns**

  The mapped fermionic operator.

  ## Definition

  This function decomposes the edge-vertex operators in terms of the fermionic action operators as defined [here](operators-edge-vertex-operator#edgevertexoperator-definition).

  ## Usage

  ```pycon
  >>> from qiskit_fermions.mappers.library import edge_vertex_to_fermion
  >>> from qiskit_fermions.operators import EdgeVertexOperator
  >>> inter_op = EdgeVertexOperator.from_dict({((0, 0),): 1, ((1, 2),): 2})
  >>> fer_op = edge_vertex_to_fermion(inter_op)
  >>> print(format(fer_op.normal_ordered().simplify()))
    1.000000e0 +0.000000e0j * ()
   -0.000000e0 +2.000000e0j * (-2 -1)
   -2.000000e0 +0.000000e0j * (+0 -0)
    0.000000e0 -2.000000e0j * (+1 -2)
   -0.000000e0 +2.000000e0j * (+2 -1)
   -0.000000e0 +2.000000e0j * (+2 +1)
  ```
