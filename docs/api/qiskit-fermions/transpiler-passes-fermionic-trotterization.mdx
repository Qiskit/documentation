# FermionicTrotterization

<Class id="qiskit_fermions.transpiler.passes.FermionicTrotterization" isDedicatedPage={true} signature="FermionicTrotterization(synthesis, *, apply=True, filter=None)" modifiers="class">
  Bases: [`F2FSynthesis`](transpiler-passes-f-2-f-synthesis "qiskit_fermions.transpiler.passes.optimization.f2f_synthesis.F2FSynthesis")

  **DEPRECATED** The former pass to Trotterize [`Evolution`](circuit-library-evolution "qiskit_fermions.circuit.library.Evolution") gates.

  This is [`F2FSynthesis`](transpiler-passes-f-2-f-synthesis "qiskit_fermions.transpiler.passes.F2FSynthesis") restricted to the [`Evolution`](circuit-library-evolution "qiskit_fermions.circuit.library.Evolution") gate: the `synthesis` argument is the method for that gate.

  Initializing this transpiler pass can be done with the arguments listed below.

  <Admonition title="Deprecated since version 0.4.0" type="danger">
    The class `qiskit_fermions.transpiler.passes.optimization._deprecated_trotterization.FermionicTrotterization` is deprecated as of qiskit-fermions 0.4.0. It will be removed no earlier than 3 months after the release date. Use F2FSynthesis(\{“Evolution”: synthesis}) instead.
  </Admonition>

  **Parameters**

  *   **synthesis** ([*F2FSynthesisPlugin*](circuit-library-synthesis-f-2-f-synthesis-plugin "qiskit_fermions.circuit.library.synthesis.F2FSynthesisPlugin")) – the synthesis method for [`Evolution`](circuit-library-evolution "qiskit_fermions.circuit.library.Evolution") gates.
  *   **apply** ([*bool*](https://docs.python.org/3/builtins/functions.html#bool)) – see [`F2FSynthesis`](transpiler-passes-f-2-f-synthesis "qiskit_fermions.transpiler.passes.F2FSynthesis").
  *   **filter** (*Callable\[\[DAGOpNode],* [*bool*](https://docs.python.org/3/builtins/functions.html#bool)*] | None*) – see [`F2FSynthesis`](transpiler-passes-f-2-f-synthesis "qiskit_fermions.transpiler.passes.F2FSynthesis").

  ## Attributes

  ### methods

  <Attribute id="qiskit_fermions.transpiler.passes.FermionicTrotterization.methods">
    Type: [`dict`](https://docs.python.org/3/builtins/stdtypes.html#dict)\[[`str`](https://docs.python.org/3/builtins/stdtypes.html#str), [`F2FSynthesisPlugin`](circuit-library-synthesis-f-2-f-synthesis-plugin "qiskit_fermions.circuit.library.synthesis.F2FSynthesisPlugin")]

    A dictionary of the fermion-to-fermion synthesis methods, by gate.

    The keys of this dictionary correspond to the `__name__` of a [`FermionicGate`](circuit-fermionic-gate "qiskit_fermions.circuit.FermionicGate"), and the values are instances of the [`F2FSynthesisPlugin`](circuit-library-synthesis-f-2-f-synthesis-plugin "qiskit_fermions.circuit.library.synthesis.F2FSynthesisPlugin") protocol. A gate that is not a key is not touched by this pass, so the dictionary is **empty** by default, which makes the pass do nothing. Pre-populate it with plugins provided by the [`F2FSynthesisPluginManager`](circuit-library-synthesis-f-2-f-synthesis-plugin-manager "qiskit_fermions.circuit.library.synthesis.F2FSynthesisPluginManager") through the `config` argument.
  </Attribute>

  ### apply

  <Attribute id="qiskit_fermions.transpiler.passes.FermionicTrotterization.apply">
    Whether to expand each selected gate into the factors its plugin produces.

    When this is `False`, the pass only *selects* the method: it tags each selected gate with its plugin (see [`FermionicGate.with_synthesis()`](circuit-fermionic-gate#with_synthesis "qiskit_fermions.circuit.FermionicGate.with_synthesis")), except an [`atomic`](circuit-fermionic-gate#atomic "qiskit_fermions.circuit.FermionicGate.atomic") gate, which is left as it is, and leaves the expansion to whatever builds the gate’s definition later, such as a [`decompose()`](circuit-fermionic-circuit#decompose "qiskit_fermions.circuit.FermionicCircuit.decompose") call. Note that a gate which is never expanded reaches the fermion-to-qubit stage whole, where it is mapped without its [`synthesis`](circuit-fermionic-gate#synthesis "qiskit_fermions.circuit.FermionicGate.synthesis") ever being read.
  </Attribute>

  ### filter

  <Attribute id="qiskit_fermions.transpiler.passes.FermionicTrotterization.filter">
    The predicate selecting which nodes to break down.
  </Attribute>

  <Function id="qiskit_fermions.transpiler.passes.FermionicTrotterization.run" signature="run(dag)">
    Runs this transpilation pass.
