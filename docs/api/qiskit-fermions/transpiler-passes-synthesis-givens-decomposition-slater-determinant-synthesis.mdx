# GivensDecompositionSlaterDeterminantSynthesis

<Class id="qiskit_fermions.transpiler.passes.synthesis.GivensDecompositionSlaterDeterminantSynthesis" isDedicatedPage={true} signature="GivensDecompositionSlaterDeterminantSynthesis(*, minimize_2q_gate_count=False)" modifiers="class">
  Bases: [`object`](https://docs.python.org/3/builtins/functions.html#object)

  **DEPRECATED** The former plugin for transpiling a [`PrepareSlaterDeterminant`](circuit-library-prepare-slater-determinant "qiskit_fermions.circuit.library.PrepareSlaterDeterminant") into Givens rotations.

  This is the [`FermionicSlaterGivensDecomposition`](circuit-library-synthesis-fermionic-slater-givens-decomposition "qiskit_fermions.circuit.library.synthesis.FermionicSlaterGivensDecomposition") followed by the Jordan-Wigner mapping of its gates.

  Initializing this plugin can be done with the argument below.

  <Admonition title="Deprecated since version 0.4.0" type="danger">
    The class `qiskit_fermions.transpiler.passes.synthesis._deprecated_givens.GivensDecompositionSlaterDeterminantSynthesis` is deprecated as of qiskit-fermions 0.4.0. It will be removed no earlier than 3 months after the release date. Break the gate down with F2FSynthesis(\{‘PrepareSlaterDeterminant’: ‘Givens’}) in the optimization stage instead, which works with any encoding.
  </Admonition>

  **Parameters**

  **minimize\_2q\_gate\_count** ([*bool*](https://docs.python.org/3/builtins/functions.html#bool)) – no longer supported. The peeling of unit-orbitals that this enabled was removed, so `True` has no effect and warns.
