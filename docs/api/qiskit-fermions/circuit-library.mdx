# Circuit Library

This module provides a library of [`FermionicGate`](/docs/api/qiskit-fermions/circuit-fermionic-gate#qiskit_fermions.circuit.FermionicGate "qiskit_fermions.circuit.FermionicGate") implementations.

|                                                                                                                                                                                                                                         |                                                                            |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| [`Evolution`](/docs/api/qiskit-fermions/circuit-library-evolution#qiskit_fermions.circuit.library.Evolution "qiskit_fermions.circuit.library.Evolution")(num\_modes, operator\[, time, ...])                                            | Implements the time evolution of an operator.                              |
| [`InitializeModes`](/docs/api/qiskit-fermions/circuit-library-initialize-modes#qiskit_fermions.circuit.library.InitializeModes "qiskit_fermions.circuit.library.InitializeModes")(occupation)                                           | Prepares (or, under simulation, certifies) a fermionic mode occupation.    |
| [`OrbitalRotation`](/docs/api/qiskit-fermions/circuit-library-orbital-rotation#qiskit_fermions.circuit.library.OrbitalRotation "qiskit_fermions.circuit.library.OrbitalRotation")(rotation\_unitary)                                    | Implements an orbital rotation.                                            |
| [`PrepareSlaterDeterminant`](/docs/api/qiskit-fermions/circuit-library-prepare-slater-determinant#qiskit_fermions.circuit.library.PrepareSlaterDeterminant "qiskit_fermions.circuit.library.PrepareSlaterDeterminant")(occupation, ...) | Prepares a Slater determinant from an occupation and an orbital rotation.  |
| [`UCC`](/docs/api/qiskit-fermions/circuit-library-ucc#qiskit_fermions.circuit.library.UCC "qiskit_fermions.circuit.library.UCC")(uccsd\_op)                                                                                             | Implements the unitary coupled-cluster singles and doubles (UCCSD) ansatz. |
| [`UCJ`](/docs/api/qiskit-fermions/circuit-library-ucj#qiskit_fermions.circuit.library.UCJ "qiskit_fermions.circuit.library.UCJ")(ucj\_op)                                                                                               | Implements the (local) unitary cluster Jastrow ((L)UCJ) ansatz.            |

Measurement is the one non-unitary operation a [`FermionicCircuit`](/docs/api/qiskit-fermions/circuit-fermionic-circuit#qiskit_fermions.circuit.FermionicCircuit "qiskit_fermions.circuit.FermionicCircuit") can carry, so it is a [`FermionicInstruction`](/docs/api/qiskit-fermions/circuit-fermionic-instruction#qiskit_fermions.circuit.FermionicInstruction "qiskit_fermions.circuit.FermionicInstruction") rather than a [`FermionicGate`](/docs/api/qiskit-fermions/circuit-fermionic-gate#qiskit_fermions.circuit.FermionicGate "qiskit_fermions.circuit.FermionicGate"):

|                                                                                                                                                                                                                    |                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| [`FermionicMeasure`](/docs/api/qiskit-fermions/circuit-library-fermionic-measure#qiskit_fermions.circuit.library.FermionicMeasure "qiskit_fermions.circuit.library.FermionicMeasure")(\*args\[, \_force\_mutable]) | A measurement of a single fermionic mode, writing its outcome into one classical bit. |

Should an [`Evolution`](/docs/api/qiskit-fermions/circuit-library-evolution#qiskit_fermions.circuit.library.Evolution "qiskit_fermions.circuit.library.Evolution") gate be decomposed in fermionic space (an optional step) how that is done is determined by a synthesis method from the [`synthesis`](circuit-library-synthesis#module-qiskit_fermions.circuit.library.synthesis "qiskit_fermions.circuit.library.synthesis") module.
