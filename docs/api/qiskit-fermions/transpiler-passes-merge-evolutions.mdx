# MergeEvolutions

<Class id="qiskit_fermions.transpiler.passes.MergeEvolutions" isDedicatedPage={true} signature="MergeEvolutions(atol=1e-12)" modifiers="class">
  Bases: [`GenericPass`](/docs/api/qiskit/qiskit.passmanager.GenericPass)\[[`DAGCircuit`](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit), [`DAGCircuit`](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit)]

  A transpilation pass merging consecutive [`Evolution`](circuit-library-evolution "qiskit_fermions.circuit.library.Evolution") gates of the same operator.

  Two evolutions under the same operator $H$ satisfy

$$
e^{-i t_2 H} e^{-i t_1 H} = e^{-i (t_1 + t_2) H},
$$

  because $H$ commutes with itself. This pass finds neighboring [`Evolution`](circuit-library-evolution "qiskit_fermions.circuit.library.Evolution") gates of equivalent operators and replaces them by one gate whose evolution time is the sum of theirs. The rewrite is exact, so it changes neither the simulated state nor the Trotter error of the circuit; it only removes a gate, and with it the synthesized operations that gate would have produced.

  Such neighbors arise wherever two sequences of factors meet on the same factor. Examples are the seams between the repetitions of [`FermionicCircuit.repeat()`](circuit-fermionic-circuit#repeat "qiskit_fermions.circuit.FermionicCircuit.repeat"), between consecutive [`UCC`](circuit-library-ucc "qiskit_fermions.circuit.library.UCC") or [`UCJ`](circuit-library-ucj "qiskit_fermions.circuit.library.UCJ") layers, or between consecutive samples of [`QDriftTrotterization`](transpiler-passes-q-drift-trotterization "qiskit_fermions.transpiler.passes.QDriftTrotterization"). [`FermionicSuzukiTrotter`](circuit-library-synthesis-fermionic-suzuki-trotter "qiskit_fermions.circuit.library.synthesis.FermionicSuzukiTrotter") already fuses the seams within its own output (see [`FermionicSuzukiTrotter.merge_adjacent`](circuit-library-synthesis-fermionic-suzuki-trotter#merge_adjacent "qiskit_fermions.circuit.library.synthesis.FermionicSuzukiTrotter.merge_adjacent")); this pass is the general mechanism which also acts across gate boundaries.

  Two gates merge only when all of the following hold:

  *   they act on the identical wires, in the identical order, with nothing else in between;
  *   their operators are of the same type and equivalent up to [`atol`](#qiskit_fermions.transpiler.passes.MergeEvolutions.atol "qiskit_fermions.transpiler.passes.MergeEvolutions.atol");
  *   they are either both `Evolution.atomic` or both not, and in the latter case they are decomposed by the same kind of `Evolution.synthesis` with identical settings.

  The merged gate keeps the operator, and thus the [`groups`](operators-operator-trait#groups "qiskit_fermions.operators.OperatorTrait.groups"), of the first gate of the run.

  ## Methods

  ### run

  <Function id="qiskit_fermions.transpiler.passes.MergeEvolutions.run" signature="run(dag)">
    Runs this transpilation pass.

    Collects every maximal run of consecutive [`Evolution`](circuit-library-evolution "qiskit_fermions.circuit.library.Evolution") gates on the same wires, splits it into stretches of mergeable gates and replaces each stretch of length two or more with a single [`Evolution`](circuit-library-evolution "qiskit_fermions.circuit.library.Evolution") carrying the summed time. Everything else is left untouched. The input DAG is modified in place.

    A `Barrier` interrupts a run, so the gates on either side of one are not merged. Place a barrier between two gates to keep them apart.

    **Parameters**

    **dag** ([*DAGCircuit*](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit)) – the input circuit with fermion-based instructions. Only [`DAGOpNode`](/docs/api/qiskit/qiskit.dagcircuit.DAGOpNode) with [`FermionicGate`](circuit-fermionic-gate "qiskit_fermions.circuit.FermionicGate") instances as their [`op`](/docs/api/qiskit/qiskit.dagcircuit.DAGOpNode#op) are supported, plus `Barrier` and [`FermionicMeasure`](circuit-library-fermionic-measure "qiskit_fermions.circuit.library.FermionicMeasure"), which are carried through untouched (a measurement keeps the classical bit it writes into).

    **Returns**

    The output circuit which is still acting on a fermionic register.

    **Return type**

    [*DAGCircuit*](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit)
  </Function>
