# F2FSynthesisPluginManager

<Class id="qiskit_fermions.circuit.library.synthesis.F2FSynthesisPluginManager" isDedicatedPage={true} signature="F2FSynthesisPluginManager" modifiers="class">
  Bases: [`object`](https://docs.python.org/3/builtins/functions.html#object)

  A simple manager of the installed fermion-to-fermion synthesis plugins.

  All plugins that are registered under the `qiskit_fermions.circuit.synthesis` [entry-point](https://setuptools.pypa.io/en/latest/userguide/entry_point.html) will be available to this class and get exposed by the [`plugins`](#qiskit_fermions.circuit.library.synthesis.F2FSynthesisPluginManager.plugins "qiskit_fermions.circuit.library.synthesis.F2FSynthesisPluginManager.plugins") attribute. The name of an entry point is the name of the gate class followed by the name of the method, separated by a dot, for example `OrbitalRotation.Givens`. Below is the table from the `pyproject.toml` of this package itself:

  ```toml
  [project.entry-points."qiskit_fermions.circuit.synthesis"]
  "Evolution.LieTrotter" = "qiskit_fermions.circuit.library.synthesis:FermionicLieTrotter"
  "Evolution.SuzukiTrotter" = "qiskit_fermions.circuit.library.synthesis:FermionicSuzukiTrotter"
  "Evolution.QDrift" = "qiskit_fermions.circuit.library.synthesis:FermionicQDrift"
  "OrbitalRotation.Givens" = "qiskit_fermions.circuit.library.synthesis:FermionicGivensDecomposition"
  "PrepareSlaterDeterminant.Givens" = "qiskit_fermions.circuit.library.synthesis:FermionicSlaterGivensDecomposition"
  ```

  An overview of all builtin plugins is given [here](/docs/api/qiskit-fermions/circuit-library-synthesis#builtin-f2f-synthesis-plugins).

  ## Attributes

  ### plugins

  <Attribute id="qiskit_fermions.circuit.library.synthesis.F2FSynthesisPluginManager.plugins">
    Type: [`dict`](https://docs.python.org/3/builtins/stdtypes.html#dict)\[[`str`](https://docs.python.org/3/builtins/stdtypes.html#str), [`list`](https://docs.python.org/3/builtins/stdtypes.html#list)\[[`str`](https://docs.python.org/3/builtins/stdtypes.html#str)]]

    A dictionary mapping gate names to their synthesis methods.

    The keys of this dictionary are names of [`FermionicGate`](circuit-fermionic-gate "qiskit_fermions.circuit.FermionicGate") classes. The values are the list of installed [`F2FSynthesisPlugin`](circuit-library-synthesis-f-2-f-synthesis-plugin "qiskit_fermions.circuit.library.synthesis.F2FSynthesisPlugin") methods that may be used to synthesize the instances of that particular gate.
  </Attribute>
