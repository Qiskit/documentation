# GivensDecompositionOrbitalRotationSynthesis

<Class id="qiskit_fermions.transpiler.passes.synthesis.GivensDecompositionOrbitalRotationSynthesis" isDedicatedPage={true} signature="GivensDecompositionOrbitalRotationSynthesis" modifiers="class">
  Bases: [`object`](https://docs.python.org/3/builtins/functions.html#object)

  **DEPRECATED** The former plugin for transpiling an [`OrbitalRotation`](circuit-library-orbital-rotation "qiskit_fermions.circuit.library.OrbitalRotation") into Givens rotations.

  This is the [`FermionicGivensDecomposition`](circuit-library-synthesis-fermionic-givens-decomposition "qiskit_fermions.circuit.library.synthesis.FermionicGivensDecomposition") followed by the Jordan-Wigner mapping of its factors.

  Initializing this plugin takes no arguments.

  <Admonition title="Deprecated since version 0.4.0" type="danger">
    The class `qiskit_fermions.transpiler.passes.synthesis._deprecated_givens.GivensDecompositionOrbitalRotationSynthesis` is deprecated as of qiskit-fermions 0.4.0. It will be removed no earlier than 3 months after the release date. Break the gate down with F2FSynthesis(\{‘OrbitalRotation’: ‘Givens’}) in the optimization stage instead, which works with any encoding.
  </Admonition>
