# HopEvolutionSynthesis

<Class id="qiskit_fermions.transpiler.passes.synthesis.HopEvolutionSynthesis" isDedicatedPage={true} signature="HopEvolutionSynthesis(*, atol=1e-12)" modifiers="class">
  Bases: [`HighLevelSynthesisPlugin`](/docs/api/qiskit/qiskit.transpiler.passes.synthesis.plugin.HighLevelSynthesisPlugin)

  A high-level synthesis plugin for the evolution under a hop between two qubits.

  A [`PauliEvolutionGate`](/docs/api/qiskit/qiskit.circuit.library.PauliEvolutionGate) whose operator is a hop (see `match_hop()`), such as the image of a fermionic hop between adjacent modes under Jordan-Wigner, is synthesized as a single [`XXPlusYYGate`](/docs/api/qiskit/qiskit.circuit.library.XXPlusYYGate). That is the exact evolution. The generic synthesis of the same operator costs several times as many two-qubit gates, and a target whose only two-qubit gate is the [`XXPlusYYGate`](/docs/api/qiskit/qiskit.circuit.library.XXPlusYYGate) cannot be reached by it at all.

  Any other gate is declined (the plugin returns `None`), so that the next method of the [`HLSConfig`](/docs/api/qiskit/qiskit.transpiler.passes.HLSConfig) is tried.

  <Admonition title="Note" type="note">
    The `synthesis` of a matched gate does not apply: the result is exact, whereas a product formula approximates the evolution of a hop with a complex amplitude (its $XX + YY$ and $XY - YX$ parts do not commute). A matched gate therefore differs from the generic synthesis by that Trotter error, and is the more accurate of the two.
  </Admonition>

  Register it ahead of the default method:

  ```python
  HLSConfig(PauliEvolution=[HopEvolutionSynthesis(), "default"])
  ```

  The [`generate_preset_jw_pass_manager()`](transpiler-presets-generate-preset-jw-pass-manager "qiskit_fermions.transpiler.presets.generate_preset_jw_pass_manager") does so unconditionally, and merges the entry into any `hls_config` passed to it. That mirrors how the preset has always lowered an orbital rotation: it emits an [`XXPlusYYGate`](/docs/api/qiskit/qiskit.circuit.library.XXPlusYYGate) for each Givens factor, and the configuration cannot turn that off.

  Initializing this plugin can be done with the arguments listed below.

  **Parameters**

  **atol** ([*float*](https://docs.python.org/3/builtins/functions.html#float)) – the absolute tolerance on the coefficients of the operator, within which it is still considered a hop.
