# MergeSlaterDeterminantPreparation

<Class id="qiskit_fermions.transpiler.passes.MergeSlaterDeterminantPreparation" isDedicatedPage={true} signature="MergeSlaterDeterminantPreparation" modifiers="class">
  Bases: [`GenericPass`](/docs/api/qiskit/qiskit.passmanager.GenericPass)\[[`DAGCircuit`](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit), [`DAGCircuit`](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit)]

  A transpilation pass fusing an initialization and rotation into a Slater determinant prep.

  An [`InitializeModes`](circuit-library-initialize-modes "qiskit_fermions.circuit.library.InitializeModes") immediately followed by an [`OrbitalRotation`](circuit-library-orbital-rotation "qiskit_fermions.circuit.library.OrbitalRotation") prepares a Slater determinant: the modes start in the reference occupation and are then rotated into the target single-particle basis. This pass detects that pattern in a [`FermionicDAGCircuit`](circuit-fermionic-dag-circuit "qiskit_fermions.circuit.FermionicDAGCircuit") and rewrites it into a single [`PrepareSlaterDeterminant`](circuit-library-prepare-slater-determinant "qiskit_fermions.circuit.library.PrepareSlaterDeterminant") gate, which a later synthesis stage can lower with the reduced-gate-count [`givens_decomposition_slater()`](linalg-givens-decomposition-slater "qiskit_fermions.linalg.givens_decomposition_slater") (via [`GivensDecompositionSlaterDeterminantSynthesis`](transpiler-passes-synthesis-givens-decomposition-slater-determinant-synthesis "qiskit_fermions.transpiler.passes.synthesis.GivensDecompositionSlaterDeterminantSynthesis")) rather than the full square orbital rotation.

  The rewrite is state-preserving: it only unlocks the cheaper synthesis and leaves the prepared state unchanged (see the *validate-then-rotate* semantics of [`PrepareSlaterDeterminant`](circuit-library-prepare-slater-determinant "qiskit_fermions.circuit.library.PrepareSlaterDeterminant")).

  Three patterns are recognized, all keyed off the block-spin mode convention (modes `0..norb` are the alpha sector, `norb..2*norb` the beta sector):

  1.  **Full-register / spinless** – an [`InitializeModes`](circuit-library-initialize-modes "qiskit_fermions.circuit.library.InitializeModes") on a mode set immediately followed by an [`OrbitalRotation`](circuit-library-orbital-rotation "qiskit_fermions.circuit.library.OrbitalRotation") on the *same* mode set fuses into one [`PrepareSlaterDeterminant`](circuit-library-prepare-slater-determinant "qiskit_fermions.circuit.library.PrepareSlaterDeterminant").
  2.  **Per-sector** – the same shape as pattern 1 but on a single spin half; it fuses into one [`PrepareSlaterDeterminant`](circuit-library-prepare-slater-determinant "qiskit_fermions.circuit.library.PrepareSlaterDeterminant") per sector.
  3.  **Global init + per-spin rotations** – a full-register (`2*norb`) [`InitializeModes`](circuit-library-initialize-modes "qiskit_fermions.circuit.library.InitializeModes") immediately followed by an [`OrbitalRotation`](circuit-library-orbital-rotation "qiskit_fermions.circuit.library.OrbitalRotation") on *either or both* contiguous spin halves (in either order) splits the occupation per sector and emits **two** [`PrepareSlaterDeterminant`](circuit-library-prepare-slater-determinant "qiskit_fermions.circuit.library.PrepareSlaterDeterminant") gates. A half that has no rotation is prepared with an identity rotation, which synthesizes to only the reference X gates – exactly what the [`InitializeModes`](circuit-library-initialize-modes "qiskit_fermions.circuit.library.InitializeModes") would have emitted for that half anyway – so padding it costs no extra gates while still unlocking the reduced Slater synthesis on the rotated half. This is the shape produced by placing an [`InitializeModes`](circuit-library-initialize-modes "qiskit_fermions.circuit.library.InitializeModes") (e.g. [`InitializeModes.from_hartree_fock()`](circuit-library-initialize-modes#from_hartree_fock "qiskit_fermions.circuit.library.InitializeModes.from_hartree_fock")) at the front of a circuit and appending a decomposed [`UCJ`](circuit-library-ucj "qiskit_fermions.circuit.library.UCJ"), whose first per-spin rotations directly follow the initialization.

  <Admonition title="See also" type="note">
    The [Slater determinant preparation guide](guides/merge-slater-determinant#merge-slater-determinant-explanation) walks through each of these patterns with before/after circuit drawings.
  </Admonition>

  “Immediately followed” is understood over the DAG: an [`OrbitalRotation`](circuit-library-orbital-rotation "qiskit_fermions.circuit.library.OrbitalRotation") node fuses only when the [`InitializeModes`](circuit-library-initialize-modes "qiskit_fermions.circuit.library.InitializeModes") is its *sole* predecessor across all of its modes, i.e. no other operation intervenes on those wires. Any arrangement not matching one of the three shapes above – non-adjacent gates, mismatched mode sets, or an [`OrbitalRotation`](circuit-library-orbital-rotation "qiskit_fermions.circuit.library.OrbitalRotation") with no preceding [`InitializeModes`](circuit-library-initialize-modes "qiskit_fermions.circuit.library.InitializeModes") – is left untouched.

  <Admonition title="Important" type="danger">
    Run this pass **after** [`MergeOrbitalRotations`](transpiler-passes-merge-orbital-rotations "qiskit_fermions.transpiler.passes.MergeOrbitalRotations"). The fusion contracts a *single* [`OrbitalRotation`](circuit-library-orbital-rotation "qiskit_fermions.circuit.library.OrbitalRotation") immediately following the [`InitializeModes`](circuit-library-initialize-modes "qiskit_fermions.circuit.library.InitializeModes"). Faced with an initialization followed by a *run* of two or more consecutive rotations, this pass only sees the first rotation immediately following the initialization – it fuses that one into a [`PrepareSlaterDeterminant`](circuit-library-prepare-slater-determinant "qiskit_fermions.circuit.library.PrepareSlaterDeterminant") but leaves the remaining rotations of the run as separate trailing [`OrbitalRotation`](circuit-library-orbital-rotation "qiskit_fermions.circuit.library.OrbitalRotation") gates, which synthesize with their full (phase-carrying) square decomposition. Running [`MergeOrbitalRotations`](transpiler-passes-merge-orbital-rotations "qiskit_fermions.transpiler.passes.MergeOrbitalRotations") first collapses the whole run into one rotation, so this pass can then contract the entire run into a single [`PrepareSlaterDeterminant`](circuit-library-prepare-slater-determinant "qiskit_fermions.circuit.library.PrepareSlaterDeterminant") and the cheaper Slater synthesis covers all of it. The preset Jordan-Wigner pipeline ([`generate_preset_jw_pass_manager()`](transpiler-presets-generate-preset-jw-pass-manager "qiskit_fermions.transpiler.presets.generate_preset_jw_pass_manager")) wires the two passes in this order.
  </Admonition>
