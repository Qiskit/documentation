# F2QSynthesisPlugin

  ## Methods

  ### run

  <Function id="qiskit_fermions.transpiler.passes.synthesis.F2QSynthesisPlugin.run" signature="run(in_node, out_dag, *, f2q_layout)">
    Translates the provided fermion-based circuit instruction to a qubit-based one.

    **Parameters**

    *   **in\_node** ([*DAGOpNode*](/docs/api/qiskit/qiskit.dagcircuit.DAGOpNode)) – a fermion-based circuit instruction stored in a [`DAGOpNode`](/docs/api/qiskit/qiskit.dagcircuit.DAGOpNode). Specifically, this guarantees that [`op`](/docs/api/qiskit/qiskit.dagcircuit.DAGOpNode#op) is of type [`FermionicGate`](circuit-fermionic-gate "qiskit_fermions.circuit.FermionicGate").
    *   **out\_dag** ([*DAGCircuit*](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit)) – the qubit-based [`DAGCircuit`](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit) into which this plugin must insert the translated circuit instruction.
    *   **f2q\_layout** ([*dict*](https://docs.python.org/3/library/stdtypes.html#dict)*\[*[*QuantumRegister*](/docs/api/qiskit/circuit#qiskit.circuit.QuantumRegister)*,* [*QuantumRegister*](/docs/api/qiskit/circuit#qiskit.circuit.QuantumRegister)*]*) – the [`F2QLayout`](transpiler-f-2-q-layout "qiskit_fermions.transpiler.F2QLayout") setting that is global to the transpilation process. It is the plugin’s responsibility to respect this mapping of [`FermionicRegister`](circuit-fermionic-register "qiskit_fermions.circuit.FermionicRegister") to [`QuantumRegister`](/docs/api/qiskit/circuit#qiskit.circuit.QuantumRegister).

    **Return type**

    None
  </Function>
