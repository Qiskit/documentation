# SupportsCommutators

<Class id="qiskit_fermions.protocols.SupportsCommutators" isDedicatedPage={true} signature="SupportsCommutators(*args, **kwargs)" modifiers="class">
  Bases: [`Protocol`](https://docs.python.org/3/library/typing.html#typing.Protocol)

  A Protocol indicating support for efficient commutator generation.

  Implementation of this protocol requires the three methods below. See [`commutator()`](operators-library-commutator "qiskit_fermions.operators.library.commutator"), [`anti_commutator()`](operators-library-anti-commutator "qiskit_fermions.operators.library.anti_commutator"), and [`double_commutator()`](operators-library-double-commutator "qiskit_fermions.operators.library.double_commutator") for the type-agnostic helper functions dispatching to these methods.

  ```pycon
  >>> from qiskit_fermions.operators import FermionOperator
  >>> cre_0 = FermionOperator.from_dict({((True, 0),): 1.0})
  >>> ann_0 = FermionOperator.from_dict({((False, 0),): 1.0})
  >>> comm = FermionOperator._commutator_(cre_0, ann_0)
  >>> print(format(comm.normal_ordered().simplify()))
   -1.000000e0 +0.000000e0j * ()
    2.000000e0 +0.000000e0j * (+0 -0)
  ```
