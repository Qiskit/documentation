# PostCircuitBitFlipChecksOptionsModel

<Class id="ibm_quantum_schemas.noise_learner_v3.version_0_3.PostCircuitBitFlipChecksOptionsModel" isDedicatedPage={true} github="https://github.com/Qiskit/ibm-quantum-schemas/tree/0.11.20260824/ibm_quantum_schemas/noise_learner_v3/version_0_3/models.py#L59-L79" signature="PostCircuitBitFlipChecksOptionsModel" modifiers="pydantic model">
  Bases: `BaseModel`

  Options to apply post-circuit bit-flip checks to the results of noise learning circuits.

  ### enable

  <Attribute id="ibm_quantum_schemas.noise_learner_v3.version_0_3.PostCircuitBitFlipChecksOptionsModel.enable" modifiers="field">
    Type: `bool`

    Default value: `False`

    Whether to apply post-circuit bit-flip checks.

    If `False`, all the other fields will be ignored.
  </Attribute>

  ### strategy

  <Attribute id="ibm_quantum_schemas.noise_learner_v3.version_0_3.PostCircuitBitFlipChecksOptionsModel.strategy" modifiers="field">
    Type: `Literal`\[`'node'`, `'edge'`]

    Default value: `'node'`

    The strategy used to decide if a shot should be kept or discarded.

    The available strategies are:

    *   `'node'`: Discard every shot where one or more bits failed to flip. Keep every other shot.
    *   `'edge'`: Discard every shot where there exists a pair of neighbouring qubits for which both of the bits failed to flip. Keep every other shot.
  </Attribute>

  ### x\_pulse\_type

  <Attribute id="ibm_quantum_schemas.noise_learner_v3.version_0_3.PostCircuitBitFlipChecksOptionsModel.x_pulse_type" modifiers="field">
    Type: `Literal`\[`'xslow'`, `'rx'`]

    Default value: `'xslow'`

    The type of the X-pulse used for the post-circuit bit-flip checks.
  </Attribute>
</Class>
