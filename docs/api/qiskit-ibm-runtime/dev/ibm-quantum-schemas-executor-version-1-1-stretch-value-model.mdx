# StretchValueModel

<Class id="ibm_quantum_schemas.executor.version_1_1.StretchValueModel" isDedicatedPage={true} github="https://github.com/Qiskit/ibm-quantum-schemas/tree/0.11.20260824/ibm_quantum_schemas/executor/version_1_1/models.py#L239-L260" signature="StretchValueModel" modifiers="pydantic model">
  Bases: `BaseModel`

  Describes circuit stretch value resolutions.

  All timing information is expressed in terms of multiples of the quantity `dt`, time step duration of the control electronics, which can be queried in backend and target properties.

  ### expanded\_values

  <Attribute id="ibm_quantum_schemas.executor.version_1_1.StretchValueModel.expanded_values" modifiers="field">
    Type: `list`\[`tuple`\[`int`, `int`]]

    A sequence of pairs `(time, duration)` indicating the time and duration of each delay.

    All units are `dt`, where the `time` denotes the absolute time of a delay in the circuit schedule, and the `duration` denotes the total duration of the delay.
  </Attribute>

  ### name

  <Attribute id="ibm_quantum_schemas.executor.version_1_1.StretchValueModel.name" modifiers="field">
    Type: `str`

    The name of the stretch.
  </Attribute>

  ### remainder

  <Attribute id="ibm_quantum_schemas.executor.version_1_1.StretchValueModel.remainder" modifiers="field">
    Type: `int`

    The time left over if `value` were to be used each stretch, in units of `dt`.
  </Attribute>

  ### value

  <Attribute id="ibm_quantum_schemas.executor.version_1_1.StretchValueModel.value" modifiers="field">
    Type: `int`

    The resolved stretch value, up to the remainder, in units of `dt`.
  </Attribute>
</Class>
