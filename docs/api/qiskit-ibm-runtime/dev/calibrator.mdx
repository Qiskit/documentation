# Calibrator

<Class id="qiskit_ibm_runtime.Calibrator" isDedicatedPage={true} github="https://github.com/Qiskit/qiskit-ibm-runtime/tree/main/qiskit_ibm_runtime/calibrator/calibrator.py#L37-L155" signature="Calibrator(mode=None, options=None)" modifiers="class">
  Bases: `object`

  Class for calibrating a backend.

  A calibrator can be initialized only inside a session. The [`run()`](#qiskit_ibm_runtime.Calibrator.run "qiskit_ibm_runtime.Calibrator.run") method can be used to submit a calibration request for a backend.

  ```python
  from qiskit_ibm_runtime import QiskitRuntimeService, Session, Calibrator

  service = QiskitRuntimeService()
  backend = service.backend("ibm_boston")

  with Session(backend=backend) as session:
      calibrator = Calibrator(session)
      calibrator.run()
  ```

  **Parameters**

  *   **mode** (*BackendV2 |* [*Session*](session "qiskit_ibm_runtime.Session")  *|*[*Batch*](batch "qiskit_ibm_runtime.Batch") *| str | None*) –

      The execution mode used to make the primitive query. It can be:

      *   A `Backend` if you are using job mode.
      *   A [`Session`](session "qiskit_ibm_runtime.Session") if you are using session execution mode.
      *   A [`Batch`](batch "qiskit_ibm_runtime.Batch") if you are using batch execution mode.

      Refer to the [IBM Quantum Compute documentation](/docs/guides/execution-modes) for more information about the `Execution modes`.

  *   **options** ([*CalibratorOptions*](options-models-calibrator-options "qiskit_ibm_runtime.options_models.calibrator.CalibratorOptions")) – Calibrator options, see [`CalibratorOptions`](options-models-calibrator-options "qiskit_ibm_runtime.options_models.CalibratorOptions") for detailed description.
