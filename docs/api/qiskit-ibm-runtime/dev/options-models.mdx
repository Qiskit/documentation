# Primitive options models

`qiskit_ibm_runtime.options_models`

Options that can be passed to [`Executor`](/docs/api/qiskit-ibm-runtime/dev/executor#qiskit_ibm_runtime.Executor "qiskit_ibm_runtime.Executor"), `NoiseLearnerV3` and client-side primitives ([`SamplerV2`](/docs/api/qiskit-ibm-runtime/dev/executor-sampler-sampler-v2#qiskit_ibm_runtime.executor_sampler.SamplerV2 "qiskit_ibm_runtime.executor_sampler.SamplerV2") and ([`EstimatorV2`](/docs/api/qiskit-ibm-runtime/dev/executor-estimator-estimator-v2#qiskit_ibm_runtime.executor_estimator.EstimatorV2 "qiskit_ibm_runtime.executor_estimator.EstimatorV2")).
