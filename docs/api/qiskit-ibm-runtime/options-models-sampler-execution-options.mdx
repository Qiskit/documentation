# qiskit\_ibm\_runtime.options\_models.SamplerExecutionOptions

<Class id="qiskit_ibm_runtime.options_models.SamplerExecutionOptions" isDedicatedPage={true} github="https://github.com/Qiskit/qiskit-ibm-runtime/tree/stable/0.50/qiskit_ibm_runtime/options_models/execution.py#L57-L69" signature="SamplerExecutionOptions" modifiers="pydantic model">

  ### init\_qubits

  <Attribute id="qiskit_ibm_runtime.options_models.SamplerExecutionOptions.init_qubits" modifiers="field">
    Type: `bool`

    Default value: `True`

    Whether to reset the qubits to the ground state for each shot.
  </Attribute>

  ### meas\_type

  <Attribute id="qiskit_ibm_runtime.options_models.SamplerExecutionOptions.meas_type" modifiers="field">
    Type: `Literal`\[`'classified'`, `'kerneled'`, `'avg_kerneled'`]

    Default value: `'classified'`

    How to process and return measurement results.

    This option sets the return type of all classical registers in all sampler pub results.

    *   `"classified"`: Returns a BitArray with classified measurement outcomes.

    *   **`"kerneled"`: Returns complex IQ data points from kerneling the measurement trace, in**

        arbitrary units.

    *   `"avg_kerneled"`: Returns complex IQ data points averaged over shots, in arbitrary units.
  </Attribute>

  ### rep\_delay

  <Attribute id="qiskit_ibm_runtime.options_models.SamplerExecutionOptions.rep_delay" modifiers="field">
    Type: `float` | `None`

    Default value: `None`

    The repetition delay.

    This is the delay between a measurement and the subsequent quantum circuit. This is only supported on backends that have `backend.dynamic_reprate_enabled=True`. It must be from the range supplied by `backend.rep_delay_range`.

    Default is given by `backend.default_rep_delay`.
  </Attribute>

  ### scheduler\_timing

  <Attribute id="qiskit_ibm_runtime.options_models.SamplerExecutionOptions.scheduler_timing" modifiers="field">
    Type: `bool`

    Default value: `False`

    Whether to return circuit schedule timing of each provided quantum circuit.

    Setting this value to `True` will cause corresponding metadata of every program item to be populated in the returned data.

    <Admonition title="Note" type="note">
      This feature is experimental and subject to change without notice.
    </Admonition>
  </Attribute>

  ### stretch\_values

  <Attribute id="qiskit_ibm_runtime.options_models.SamplerExecutionOptions.stretch_values" modifiers="field">
    Type: `bool`

    Default value: `False`

    Whether to return numeric resolutions of stretches for each provided quantum circuit.

    Setting this value to `True` will cause corresponding metadata of every program item to be populated in the returned data.

    <Admonition title="Note" type="note">
      This feature is experimental and subject to change without notice.
    </Admonition>
  </Attribute>
