# qiskit\_ibm\_runtime.options\_models.DynamicalDecouplingOptions

<Class id="qiskit_ibm_runtime.options_models.DynamicalDecouplingOptions" isDedicatedPage={true} github="https://github.com/Qiskit/qiskit-ibm-runtime/tree/stable/0.50/qiskit_ibm_runtime/options_models/dynamical_decoupling.py#L22-L54" signature="DynamicalDecouplingOptions" modifiers="pydantic model">

  ### enable

  <Attribute id="qiskit_ibm_runtime.options_models.DynamicalDecouplingOptions.enable" modifiers="field">
    Type: `bool`

    Default value: `False`

    Whether to enable DD as specified by the other options in this class.
  </Attribute>

  ### extra\_slack\_distribution

  <Attribute id="qiskit_ibm_runtime.options_models.DynamicalDecouplingOptions.extra_slack_distribution" modifiers="field">
    Type: `Literal`\[`'middle'`, `'edges'`]

    Default value: `'middle'`

    Where to put extra timing delays due to rounding issues.

    Rounding issues arise because the discrete time step `dt` of the system cannot be divided.

    *   `"middle"`: Put the extra slack to the interval at the middle of the sequence.

    *   **`"edges"`: Divide the extra slack as evenly as possible into intervals at beginning and end**

        of the sequence.
  </Attribute>

  ### scheduling\_method

  <Attribute id="qiskit_ibm_runtime.options_models.DynamicalDecouplingOptions.scheduling_method" modifiers="field">
    Type: `Literal`\[`'alap'`, `'asap'`]

    Default value: `'alap'`

    Whether to schedule gates as soon as (“asap”) or as late as (“alap”) possible.
  </Attribute>

  ### sequence\_type

  <Attribute id="qiskit_ibm_runtime.options_models.DynamicalDecouplingOptions.sequence_type" modifiers="field">
    Type: `Literal`\[`'XX'`, `'XpXm'`, `'XY4'`]

    Default value: `'XX'`

    Which dynamical decoupling sequence to use.

    *   `"XX"`: use the sequence `tau/2 - (+X) - tau - (+X) - tau/2`
    *   `"XpXm"`: use the sequence `tau/2 - (+X) - tau - (-X) - tau/2`
    *   `"XY4"`: use the sequence `tau/2 - (+X) - tau - (+Y) - tau (-X) - tau - (-Y) - tau/2`
  </Attribute>

  ### skip\_reset\_qubits

  <Attribute id="qiskit_ibm_runtime.options_models.DynamicalDecouplingOptions.skip_reset_qubits" modifiers="field">
    Type: `bool`

    Default value: `False`

    Whether to insert DD on idle periods that immediately follow initialized/reset qubits.

    Since qubits in the ground state are less susceptible to decoherence, it can be beneficial to let them be while they are known to be in this state.
  </Attribute>
