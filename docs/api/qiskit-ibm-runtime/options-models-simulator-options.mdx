  ### angle\_decimals

  <Attribute id="qiskit_ibm_runtime.options_models.SimulatorOptions.angle_decimals" modifiers="field">
    Type: `int`

    Default value: `5`

    Gate angle decimal precision.

    Gate angles are rounded to the nearest multiple of `np.pi/2` at this decimal precision before simulation. This prevents floating-point drift from preventing Clifford-method simulation when angles are nominally Clifford.
  </Attribute>

  ### layer\_noise\_model

  <Attribute id="qiskit_ibm_runtime.options_models.SimulatorOptions.layer_noise_model" modifiers="field">
    Type: `list`\[`LayerNoiseModel`] | `None`

    Default value: `None`

    Noise model specified by a collection of instructions and the noise that affects them.

    When simulating an estimator job, if this value is set to `None`, it defaults to the value of [`qiskit_ibm_runtime.options_models.ResilienceOptions.layer_noise_model`](options-models-resilience-options#layer_noise_model "qiskit_ibm_runtime.options_models.ResilienceOptions.layer_noise_model").
