# PEC (`qiskit_mitigation.pec`)

### PEC

<Class id="qiskit_mitigation.PEC" github="https://github.com/Qiskit/qiskit-mitigation/tree/main/qiskit_mitigation/pec.py#L64-L1022" signature="PEC" modifiers="class">
  Bases: [`MitigationTask`](mitigation-task#qiskit_mitigation.MitigationTask "qiskit_mitigation.mitigation_task.MitigationTask")

  Calculates expectation values of observables using Probabilistic Error Cancellation (PEC) mitigation method.

  The class enables preparing a QuantumProgram with circuit mitigated using PEC method, that can be executed on hardware using the Executor, and post process the results to calculate mitigated expectation values of given observables. The task parameters should be given as input to the prepare function, and the relevant variables needed for post-processing are saved internally:

  ```python
  pec = PEC()
  program = pec.prepare(circuit=circuit,
                        observables=observables,
                        parameters=parameter_valuesת
                        noise_maps=learned_noise)
  job = executor.run(program)
  results = job.result()
  mitigated_result = pec.postprocess(results)
  ```

  To calculate expectation values of a loaded job result, a PEC task can be created from the job results with all the internal variables needed for post-processing. Alternatively, the variables required for post-processing can be given as input directly to the `compute_expectation_value` static method. Example for running post-processing for a loaded result:

  ```python
  pec = PEC()
  program = pec.prepare(circuit=circuit,
                        observables=observables,
                        parameters=parameter_valuesת
                        noise_maps=learned_noise)
  job_id = executor.run(program).job_id

  job = service.job(job_id)
  results = job.result()
  pec = load_tasks_from_result(results)[0]
  mitigated_result = pec.postprocess(results)
  ```

  Instantiate a PEC task.

    *   **box\_types** ([*Literal*](https://docs.python.org/3/library/typing.html#typing.Literal)*\['gates', 'measurement', 'all']*) – Can be either `"gates"`, `"measurement"` or `"all"`, corresponding to filter boxes with only gate layers, only measurement layers or all layers, respectively.

  ##### prepare

  <Function id="qiskit_mitigation.PEC.prepare" github="https://github.com/Qiskit/qiskit-mitigation/tree/main/qiskit_mitigation/pec.py#L168-L422" signature="prepare(circuit, observables, parameters, custom_boxing_options=None, shots_per_randomization=64, num_randomizations=128, broadcast_obs_and_params=False, trex=None, quantum_program=None, trim_measurements=False, *, noise_maps=None, scale_randomizations_by_gamma=True, noise_gain='auto', max_sampling_overhead=100)">
    Creates a `QuantumProgram` with PEC mitigated item for executing via Executor.

    Creates an item for a `QuantumProgram`, that can be executed via Executor and is PEC mitigated (injects inverse noise to cancel the learned noise). If a `quantum_program` is provided, the new item will be added to the existing program, otherwise, a new program will be created, containing only the created item. In the created program item the final measurement layer of the given circuit is removed and a new measurement layer with a dedicated classical register named `_meas` is added. If `broadcast_obs_and_params` is True, the observables and parameters will be broadcasted using the samplomatic broadcasting rules, to allow attaching some of the parameters to some of the observables. Otherwise, every parameter will be executed for each observable (outer product of the parameters and observables). Note that the post-processing of an outer product is usually faster.

    **Parameters**

    *   **circuit** ([*QuantumCircuit*](/docs/api/qiskit/qiskit.circuit.QuantumCircuit)) – The quantum circuit.

    *   **observables** ([*ObservablesArray*](/docs/api/qiskit/qiskit.primitives.ObservablesArray)  *|*[*Sequence*](https://docs.python.org/3/library/collections.abc.html#collections.abc.Sequence)*\[*[*SparsePauliOp*](/docs/api/qiskit/qiskit.quantum_info.SparsePauliOp)*]*) – The observables to calculate their expectation values.

    *   **parameters** ([*ndarray*](https://numpy.org/doc/stable/reference/generated/numpy.ndarray.html#numpy.ndarray)  *|*[*BindingsArray*](/docs/api/qiskit/qiskit.primitives.BindingsArray) *| None*) – The parameters of a parametric circuit.

    *   **custom\_boxing\_options** ([*dict*](https://docs.python.org/3/builtins/stdtypes.html#dict) *| None*) – The custom boxing options that will be used by `generate_boxing_pass_manager()` function.

    *   **shots\_per\_randomization** ([*int*](https://docs.python.org/3/builtins/functions.html#int)) – The number of shots per randomization.

    *   **num\_randomizations** ([*int*](https://docs.python.org/3/builtins/functions.html#int)) – The number of randomizations.

    *   **broadcast\_obs\_and\_params** ([*bool*](https://docs.python.org/3/builtins/functions.html#bool)) – Whether to broadcast observables and parameters.

    *   **trex** ([*TREX*](trex#qiskit_mitigation.TREX "qiskit_mitigation.trex.TREX") *| None*) – A TREX mitigation instance that will be used to mitigate readout errors.

    *   **quantum\_program** ([*QuantumProgram*](/docs/api/samplomatic/auto/quantum-program-quantum-program#samplomatic.quantum_program.QuantumProgram "(in samplomatic)") *| None*) – The quantum program to add an item for. If None, a new program will be created.

    *   **trim\_measurements** ([*bool*](https://docs.python.org/3/builtins/functions.html#bool)) –

        Whether to measure only the qubits that have instructions on them or are in the support of the observables, instead of all the qubits of the circuit. The measured qubits are available in `meas_qubits` after the call.

            <Admonition title="Warning" type="caution">
              Trimming changes the boxing of the circuit, so `noise_maps` must be learned on the layers of a trimmed circuit: pass `observables` to the layer finder (`find_combined_unique_layers()` or [`find_unique_layers()`](mitigation-task#qiskit_mitigation.MitigationTask.find_unique_layers "qiskit_mitigation.MitigationTask.find_unique_layers")) if and only if `trim_measurements=True` is passed to `prepare`, and pass the same observables.
            </Admonition>

    *   **noise\_maps** ([*dict*](https://docs.python.org/3/builtins/stdtypes.html#dict)*\[*[*str*](https://docs.python.org/3/builtins/stdtypes.html#str)*,* [*PauliLindbladMap*](/docs/api/qiskit/qiskit.quantum_info.PauliLindbladMap)*] | None*) – A mapping between layer ref to a noise model to use for PEC mitigation method. The dict might contain layers not present in the given circuit, but must contain all the mitigated layers. Assumes that the unique layers used for noise learning were extracted using the `find_unique_layers` method with the same custom boxing options, and with `observables` passed if and only if `trim_measurements=True`.

    *   **scale\_randomizations\_by\_gamma** ([*bool*](https://docs.python.org/3/builtins/functions.html#bool)) – Whether to automatically scale the number of randomizations by gamma\*\*2.

    *   **noise\_gain** ([*float*](https://docs.python.org/3/builtins/functions.html#float)  *|*[*Literal*](https://docs.python.org/3/library/typing.html#typing.Literal)*\['auto', 'slc\_local\_scales']*) – The fraction of noise to keep after the mitigation. A value of `0` corresponds to removing the full learned noise. A value of `1` corresponds to no removal of the learned noise. A value between `0` and `1` corresponds to partially removing the learned noise. A value greater than one corresponds to amplifying the learned noise. A value of “slc\_local\_scales” corresponds to partially removing the learned noise of each box according to the local scales learned using shaded light-cones (slc). In order to compute those local scales, first use [`generate_slc_bounds_computation_input()`](#qiskit_mitigation.PEC.generate_slc_bounds_computation_input "qiskit_mitigation.PEC.generate_slc_bounds_computation_input") and the `qiskit-addon-slc` bounds functions, and then use [`set_slc_local_scales()`](#qiskit_mitigation.PEC.set_slc_local_scales "qiskit_mitigation.PEC.set_slc_local_scales") (see its documentation). If `"auto"`, the value in the range `[0, 1]` will be chosen automatically by the formula `1 - log(max_overhead) / log(gamma^2)`.

    *   **max\_sampling\_overhead** ([*float*](https://docs.python.org/3/builtins/functions.html#float) *| None*) – If scale\_randomizations\_by\_gamma is True, limit the multiplicative ratio of the number of randomizations.

    **Returns**

    A `QuantumProgram` with PEC mitigated item that can be executed via Executor.

    **Raises**

    [**ValueError**](https://docs.python.org/3/builtins/exceptions.html#ValueError) – If `trim_measurements` is `True` and no qubit is active or observed.

    **Return type**

    [*QuantumProgram*](/docs/api/samplomatic/auto/quantum-program-quantum-program#samplomatic.quantum_program.QuantumProgram "(in samplomatic)")
  </Function>

  ##### generate\_slc\_bounds\_computation\_input

  <Function id="qiskit_mitigation.PEC.generate_slc_bounds_computation_input" github="https://github.com/Qiskit/qiskit-mitigation/tree/main/qiskit_mitigation/pec.py#L535-L612" signature="generate_slc_bounds_computation_input(circuit, coupling_map=None, custom_boxing_options=None)">
    Prepare the inputs required for computing the shaded light-cone (SLC) bounds of a circuit.

    The circuit is boxed, and the Pauli error terms of each noisy layer are generated using `qiskit_addon_slc.utils.generate_noise_model_paulis()`. The circuit, boxed circuit and the boxing options are saved in the class instance. If the instance already holds a boxed circuit of the given `circuit` (for example, from a previous call to this function or to `prepare`), and `custom_boxing_options` is `None` or equal to the saved boxing options, the saved boxed circuit is reused instead of boxing the circuit again.

    <Admonition title="Important" type="danger">
      The bounds are keyed by the `modifier_ref` of each noisy box, so `custom_boxing_options["inject_noise_strategy"]` must be `"individual_modification"` (see `qiskit_addon_slc.bounds.compute_forward_bounds()`). If it is not specified, it is set to `"individual_modification"`. If `custom_boxing_options` is `None` and the saved boxing options are used, the same rule applies to them.
    </Admonition>

    <Admonition title="Note" type="note">
      This function uses the optional dependency of `qiskit-addon-slc` package.
    </Admonition>

    **Parameters**

    *   **circuit** ([*QuantumCircuit*](/docs/api/qiskit/qiskit.circuit.QuantumCircuit)) – The target circuit to compute bounds for.
    *   **coupling\_map** ([*CouplingMap*](/docs/api/qiskit/qiskit.transpiler.CouplingMap) *| None*) – The coupling map of the backend on which the instructions have been laid out. Used to generate all the relevant Pauli error terms. If `None`, a 1d line of qubits is assumed.
    *   **custom\_boxing\_options** ([*dict*](https://docs.python.org/3/builtins/stdtypes.html#dict) *| None*) – The custom boxing options that will be used by `generate_boxing_pass_manager()` function. If `None` and `circuit` is the same object as the circuit saved in the class instance (e.g. from a previous call to `prepare`), the `custom_boxing_options` saved in the instance are used.

    **Returns**

    *   The boxed circuit.
    *   A dict mapping the ref of each noise model to the Pauli error terms to consider. Can be given as the `noise_model_paulis` input of the `qiskit-addon-slc` bounds functions.

    **Raises**

    *   **MissingOptionalLibraryError** – if `qiskit-addon-slc` package is not installed.
    *   [**ValueError**](https://docs.python.org/3/builtins/exceptions.html#ValueError) – If the circuit has unbounded parameters.
    *   [**ValueError**](https://docs.python.org/3/builtins/exceptions.html#ValueError) – If `custom_boxing_options["inject_noise_strategy"]` is specified and is not `"individual_modification"`.

    **Return type**

    [tuple](https://docs.python.org/3/builtins/stdtypes.html#tuple)\[[*QuantumCircuit*](/docs/api/qiskit/qiskit.circuit.QuantumCircuit), [dict](https://docs.python.org/3/builtins/stdtypes.html#dict)\[[str](https://docs.python.org/3/builtins/stdtypes.html#str), [*QubitSparsePauliList*](/docs/api/qiskit/qiskit.quantum_info.QubitSparsePauliList)]]

  ##### set\_slc\_local\_scales

  <Function id="qiskit_mitigation.PEC.set_slc_local_scales" github="https://github.com/Qiskit/qiskit-mitigation/tree/main/qiskit_mitigation/pec.py#L614-L675" signature="set_slc_local_scales(local_scales, reduced_gamma, reduced_bias=None)">
    Set the shaded light-cone (SLC) local scales and reduced gamma on the instance.

    These values determine which individual Pauli error terms are mitigated and at what cost when `noise_gain="slc_local_scales"` is passed to [`prepare()`](#qiskit_mitigation.PEC.prepare "qiskit_mitigation.PEC.prepare").

    The parameters `local_scales`, `reduced_gamma`, and `reduced_bias` can be computed using the `qiskit-addon-slc` package. See the [package guide](/docs/addons/qiskit-addon-slc/guides/quickstart) for more information. A summary of the computation flow is shown below.

    1.  Call [`generate_slc_bounds_computation_input()`](#qiskit_mitigation.PEC.generate_slc_bounds_computation_input "qiskit_mitigation.PEC.generate_slc_bounds_computation_input") with the target circuit to obtain the boxed circuit and `noise_model_paulis`.

    2.  Compute the bounds to pass to `qiskit_addon_slc.bounds.compute_local_scales()`. At least one direction is required. Examples:

        *   **Forward only** (optionally tightened):

            ```python
            bounds = compute_forward_bounds(boxed_circuit, noise_model_paulis, observable)
            bounds = tighten_with_speed_limit(bounds, boxed_circuit, noise_model_paulis, observable)  # optional
            ```

        *   **Backward only**:

            ```python
            bounds = compute_backward_bounds(boxed_circuit, noise_model_paulis)
            ```

        *   **Both directions merged** (use `qiskit_addon_slc.bounds.merge_bounds()`):

            ```python
            bounds = merge_bounds(
                boxed_circuit,
                tighten_with_speed_limit(
                    compute_forward_bounds(boxed_circuit, noise_model_paulis, observable),
                    boxed_circuit, noise_model_paulis, observable,
                ),
                compute_backward_bounds(boxed_circuit, noise_model_paulis),
                noise_maps,
            )
            ```

    3.  Call `qiskit_addon_slc.bounds.compute_local_scales()` with either a `sampling_cost_budget` (upper bound on gamma^2) or a `bias_tolerance` (upper bound on the remaining bias) to obtain `local_scales`, `sampling_cost`, and `reduced_bias`. Pass `sqrt(sampling_cost)` as `reduced_gamma`:

        ```python
        local_scales, sampling_cost, reduced_bias = compute_local_scales(
            boxed_circuit, bounds, noise_maps, sampling_cost_budget=<budget>
        )
        ```
