# FunctionsCatalog

<Class id="qiskit_ibm_catalog.FunctionsCatalog" isDedicatedPage={true} github="https://github.com/Qiskit/qiskit-ibm-catalog/blob/v0.22.0/qiskit_ibm_catalog/catalog.py" signature="qiskit_ibm_catalog.FunctionsCatalog(token=None, channel=None, instance=None, name=None)" modifiers="class">
  Client for loading and running Quantum Functions from the [Functions Catalog](/docs/guides/functions). `QiskitFunctionsCatalog` is an alias.

  Pass credentials to the constructor, or save them once with [`save_account()`](#save_account) and construct the client with no arguments. If `token` is set, `name` is ignored.

  ```python
  from qiskit_ibm_catalog import FunctionsCatalog

  catalog = FunctionsCatalog(token="<API_KEY>", instance="<CRN>")
  function = catalog.load("qedma/qesem")
  job = function.run(**inputs)
  result = job.result()
  ```

  **Parameters**

  *   **token** (*str | None*) – IBM Cloud API key.
  *   **channel** (*str | None*) – Authentication method.
  *   **instance** (*str | None*) – Cloud resource name (CRN) of your IBM Quantum Platform instance.
  *   **name** (*str | None*) – Name of a saved account to load from the local account config file.

  ## Account

  ### save\_account

  <Function id="qiskit_ibm_catalog.FunctionsCatalog.save_account" signature="save_account(token=None, channel=None, instance=None, name=None, overwrite=False)" modifiers="static">
    Saves the account to disk for future use.

  </Function>

  ## Find functions

  ### list

  <Function id="qiskit_ibm_catalog.FunctionsCatalog.list" signature="list(*, limit=None, offset=None, **kwargs)">
    Lists the functions available to you in the catalog.

    ```python
    for function in catalog.list():
        print(function.title)
    ```

    Output:

    ```text
    qunova/hivqe-chemistry
    qedma/qesem
    multiverse/singularity
    ...
    ```

    **Parameters**

    *   **limit** (*int | None*) – Maximum number of functions to return.
    *   **offset** (*int | None*) – Number of functions to skip.

    **Return type**

    list\[[`RunnableQiskitFunction`](function)]
  </Function>

  ### load

  <Function id="qiskit_ibm_catalog.FunctionsCatalog.load" signature="load(title, provider=None)">
    Loads a function by title.

    ```python
    qesem_function = catalog.load("qedma/qesem")
    print(qesem_function)
    ```

    Output:

    ```text
    QiskitFunction(qedma/qesem)
    ```

    **Parameters**

    *   **title** (*str*) – Function title, in `provider/function-name` form. For example, `"qedma/qesem"`.
    *   **provider** (*str | None*) – Provider name, if not included in `title`.

    **Return type**

    [`RunnableQiskitFunction`](function) | `None`
  </Function>

  ## Jobs

  ### jobs

  <Function id="qiskit_ibm_catalog.FunctionsCatalog.jobs" signature="jobs(function=None, *, limit=10, offset=0, status=None, created_after=None, **kwargs)">
    Lists your Quantum Functions jobs.

    ```python
    catalog.jobs(
        function=qesem_function,
        status="ERROR",
        created_after="2026-01-01T00:00:00Z",
        limit=5,
    )
    ```

    Output:

    ```text
    [<Job | e6b1ffa1-cd26-437d-bd53-b265dd4ba952>,
     <Job | 11308f2a-8d7a-40a0-a970-7fdeca2b171b>]
    ```

    **Parameters**

    *   **function** ([*RunnableQiskitFunction*](function) *| None*) – Only return jobs created by this function.
    *   **limit** (*int*) – Maximum number of jobs to return.
    *   **offset** (*int*) – Number of jobs to skip.
    *   **status** (*str | None*) – One of `QUEUED`, `RUNNING`, `DONE`, `ERROR`, or `CANCELED`.
    *   **created\_after** (*str | None*) – ISO 8601 timestamp, such as `"2026-01-01T00:00:00Z"`.

    **Return type**

    list\[[`Job`](functions-job)]
  </Function>

  ### usage

  <Function id="qiskit_ibm_catalog.FunctionsCatalog.usage" signature="usage()">
    Returns Quantum Compute usage for the active instance in the current usage period. Fields that don't apply to your plan, such as limits, can be missing. `usage_remaining_seconds` is the limit, or the allocation if there's no limit, minus the time consumed. See the [instance usage endpoint](/docs/api/qiskit-runtime-rest/tags/instances#tags__instances__operations__get_usage) for every field.

    ```python
    from pprint import pprint

    pprint(catalog.usage(), sort_dicts=False)
    ```

    Output:

    ```text
    {'instance_id': 'crn:v1:bluemix:public:quantum-computing:us-east:a/...',
     'plan_id': 'flex-plan-id-1',
     'usage_period': {'start_time': '2026-10-10T00:00:00.000Z',
                      'end_time': '2026-11-07T00:00:00.000Z'},
     'usage_consumed_seconds': 12,
     'usage_consumed_ru': 0.2,
     'usage_limit_seconds': 60,
     'usage_limit_ru': 1,
     'usage_allocation_seconds': 120,
     'usage_allocation_ru': 2,
     'usage_limit_reached': False,
     'usage_remaining_seconds': 48}
    ```

    **Return type**

    `dict`
  </Function>
