# QiskitFunctionsCatalog

<Class id="qiskit_ibm_catalog.QiskitFunctionsCatalog" isDedicatedPage={true} github="https://github.com/Qiskit/qiskit-ibm-catalog/blob/v0.22.0/qiskit_ibm_catalog/catalog.py" signature="qiskit_ibm_catalog.QiskitFunctionsCatalog(token=None, channel=None, instance=None, name=None)" modifiers="class">
  Client for loading and running Qiskit Functions from the [Functions Catalog](/docs/guides/functions). `FunctionsCatalog` is an alias.

  Pass credentials to the constructor, or save them once with [`save_account()`](#save_account) and construct the client with no arguments. If `token` is set, `name` is ignored.

  ```python
  from qiskit_ibm_catalog import QiskitFunctionsCatalog

  catalog = QiskitFunctionsCatalog(token="<API_KEY>", instance="<CRN>")
  function = catalog.load("qedma/qesem")
  job = function.run(**inputs)
  result = job.result()
  ```

  **Parameters**

  *   **token** (*str | None*) – IBM Cloud API key.
  *   **channel** (*str | None*) – Authentication method.
  *   **instance** (*str | None*) – Cloud resource name (CRN) of your IBM Quantum Platform instance.
  *   **name** (*str | None*) – Name of a saved account to load from the local account config file.
