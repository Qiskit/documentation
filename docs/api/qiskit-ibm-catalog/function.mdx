# Function

<Class id="qiskit_serverless.core.function.RunnableQiskitFunction" isDedicatedPage={true} signature="qiskit_serverless.core.function.RunnableQiskitFunction" modifiers="class">
  A Quantum Function loaded with [`FunctionsCatalog.load()`](qiskit-functions-catalog#load). Its class is `RunnableQiskitFunction`. You don't create it directly.

  ## Methods

  ### get\_default\_size

  <Function id="qiskit_serverless.core.function.RunnableQiskitFunction.get_default_size" signature="get_default_size()">
    Returns the size label used when a run doesn't pass `function_size`.

    ```python
    print(qesem_function.get_default_size())
    ```

    Output:

    ```text
    None
    ```

    **Return type**

    `str | None` – `None` if the function doesn't declare a default.
  </Function>

  ### jobs

  <Function id="qiskit_serverless.core.function.RunnableQiskitFunction.jobs" signature="jobs(**kwargs)">
    Lists the jobs created with this function. Replaces the deprecated `get_jobs()`.

    ```python
    for job in qesem_function.jobs():
        print(job.job_id, job.status())
    ```

    Output:

    ```text
    f6c29f49-4d5f-4fff-aca6-2e9a115b9763 DONE
    7f08c9d5-471b-4da2-92e7-4f2cb94c23a8 ERROR
    ```

    **Return type**

    list\[[`Job`](functions-job)]
  </Function>

  ### run

  <Function id="qiskit_serverless.core.function.RunnableQiskitFunction.run" signature="run(**kwargs)">
    Starts a job and returns immediately.

    ```python
    job = qesem_function.run(
        pubs=[(circuit, observable)],
        backend_name="ibm_fez",
    )
    print(job.job_id)
    ```

    Output:

    ```text
    f6c29f49-4d5f-4fff-aca6-2e9a115b9763
    ```

    **Parameters**

    *   **\*\*kwargs** – The function's inputs. See the function's [API reference](/docs/api/functions).
    *   **function\_size** (*str | None*) – Size label, if the function declares sizes. Reserved keyword.
    *   **config** (*Configuration | None*) – Job configuration. Reserved keyword.

    **Return type**

    [`Job`](functions-job)

    **Raises**

    `QiskitServerlessException` – If the arguments are invalid.
  </Function>

  ### sizes

  <Function id="qiskit_serverless.core.function.RunnableQiskitFunction.sizes" signature="sizes()">
    Returns the size labels the function declares.

    ```python
    print(qesem_function.sizes())
    ```

    Output:

    ```text
    {}
    ```

    **Return type**

    `dict[str, str]` – Empty if the function declares no sizes.
  </Function>

  ### validate\_arguments

  <Function id="qiskit_serverless.core.function.RunnableQiskitFunction.validate_arguments" signature="validate_arguments(arguments)">
    Checks arguments against the function's schema without creating a job.

    ```python
    qesem_function.validate_arguments(
        {"pubs": [(circuit, observable)], "backend_name": "ibm_fez"}
    )
    ```

    Output:

    ```text
    {'valid': True}
    ```

    **Parameters**

    *   **arguments** (*dict*) – The arguments to check.

    **Return type**

    `dict` – `{"valid": True}` if the arguments are valid.

    **Raises**

    `QiskitServerlessException` – If the arguments are invalid.
  </Function>
</Class>
