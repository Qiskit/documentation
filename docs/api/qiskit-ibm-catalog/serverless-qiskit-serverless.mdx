# qiskit\_ibm\_catalog.serverless.QiskitServerless

<Class id="qiskit_ibm_catalog.serverless.QiskitServerless" isDedicatedPage={true} github="https://github.com/Qiskit/qiskit-ibm-catalog/tree/v0.21.0/qiskit_ibm_catalog/serverless.py" signature="QiskitServerless(token=None, channel=None, instance=None, name=None, *, host=None)" modifiers="class">
  A client for connecting to the Qiskit serverless.

  Credentials can be saved to disk by calling the save\_account() method:

  ```python
  from qiskit_ibm_catalog import QiskitServerless
  QiskitServerless.save_account(token=<INSERT_IBM_QUANTUM_TOKEN>, instance=<INSERT_CRN>)
  ```

  Once the credentials are saved, you can simply instantiate the serverless with no constructor args, as shown below.

  > from qiskit\_ibm\_catalog import QiskitServerless serverless = QiskitServerless()

  You can also enable an account just for the current session by instantiating the serverless with the API token and CRN:

  ```python
  from qiskit_ibm_catalog import QiskitServerless
  serverless = QiskitServerless(token=<INSERT_IBM_QUANTUM_TOKEN>, instance=<INSERT_CRN>)
  ```

  Initialize qiskit serverless client.

  If a `token` is used to initialize an instance, the `name` argument will be ignored.

  If only a `name` is provided, the token for the named account will be retrieved from the user’s local IBM Quantum account config file.

  **Parameters**

  *   **channel** (`Optional`\[`str`]) – identifies the method to use to authenticate the user
  *   **token** (`Optional`\[`str`]) – IBM quantum token or IBM Cloud Api Key
  *   **instance** (`Optional`\[`str`]) – IBM Cloud CRN
  *   **name** (`Optional`\[`str`]) – Name of the account to load
