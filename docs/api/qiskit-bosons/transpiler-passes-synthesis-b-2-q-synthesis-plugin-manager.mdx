# B2QSynthesisPluginManager

<Class id="qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPluginManager" isDedicatedPage={true} signature="B2QSynthesisPluginManager" modifiers="class">
  Bases: [`object`](https://docs.python.org/3/builtins/functions.html#object)

  A simple manager of the installed boson-to-qubit synthesis plugins.

  All plugins that are registered under the `qiskit_bosons.transpiler.synthesis` [entry-point](https://setuptools.pypa.io/en/latest/userguide/entry_point.html) will be available to this class and get exposed by the [`plugins`](#qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPluginManager.plugins "qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPluginManager.plugins") attribute. Below is an example from the `pyproject.toml` of this package itself:

  ```toml
  [project.entry-points."qiskit_bosons.transpiler.synthesis"]
  "Evolution.MapperFn" = "qiskit_bosons.transpiler.passes.synthesis:MapperFnEvolutionSynthesis"
  "InitializeModes.Occupation" = "qiskit_bosons.transpiler.passes.synthesis:OccupationInitializeModesSynthesis"
  ```

  An overview of all builtin plugins is given [here](/docs/api/qiskit-bosons/transpiler-passes-synthesis#builtin-b2q-synthesis-plugins).

  ## Attributes

  ### plugins

  <Attribute id="qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPluginManager.plugins">
    Type: [`dict`](https://docs.python.org/3/builtins/stdtypes.html#dict)\[[`str`](https://docs.python.org/3/builtins/stdtypes.html#str), [`list`](https://docs.python.org/3/builtins/stdtypes.html#list)\[[`str`](https://docs.python.org/3/builtins/stdtypes.html#str)]]

    A dictionary mapping circuit instruction names to their synthesis methods.

    The keys of this dictionary are names of [`BosonicGate`](circuit-bosonic-gate "qiskit_bosons.circuit.BosonicGate") classes. The values are the list of installed [`B2QSynthesisPlugin`](transpiler-passes-synthesis-b-2-q-synthesis-plugin "qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPlugin") methods that may be used to synthesize the instances of that particular gate to its qubit form.
  </Attribute>
