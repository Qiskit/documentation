# momentum

<Function id="qiskit_bosons.operators.library.momentum" isDedicatedPage={true} signature="momentum(mode)">
  Builds the dimensionless momentum (quadrature) operator of a single mode.

$$
\hat{p} = \frac{i}{\sqrt{2}}\left(b^\dagger - b\right) \, .
$$

  ```pycon
  >>> from qiskit_bosons.operators.library import momentum
  >>> momentum(0).is_hermitian()
  True
  ```

  **Parameters**

  **mode** ([*int*](https://docs.python.org/3/builtins/functions.html#int)) – the mode index.

  **Returns**

  The momentum operator as a [`BosonOperator`](operators-boson-operator "qiskit_bosons.operators.BosonOperator").

  **Return type**

  [*BosonOperator*](operators-boson-operator "qiskit_bosons.operators.boson_operator.BosonOperator")
</Function>
