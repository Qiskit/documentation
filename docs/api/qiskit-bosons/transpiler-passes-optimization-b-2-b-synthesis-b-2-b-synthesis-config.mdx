# B2BSynthesisConfig

<Attribute id="qiskit_bosons.transpiler.passes.optimization.b2b_synthesis.B2BSynthesisConfig" isDedicatedPage={true}>
  The dictionary type used to configure the [`B2BSynthesis.methods`](transpiler-passes-b-2-b-synthesis#methods "qiskit_bosons.transpiler.passes.B2BSynthesis.methods").

  The keys of this dictionary must be names of [`BosonicGate`](circuit-bosonic-gate "qiskit_bosons.circuit.BosonicGate") classes that can be broken down in bosonic space. The values can be one of four types:

  1.  `str`: the simplest scenario simply specifies the name of the plugin method to use for the corresponding key in this dictionary. The plugin is extracted from the [`B2BSynthesisPluginManager`](circuit-library-synthesis-b-2-b-synthesis-plugin-manager "qiskit_bosons.circuit.library.synthesis.B2BSynthesisPluginManager") and its `__init__` method may **not** require any arguments.
  2.  `tuple[str, Sequence[Any]]`: the first `str` is the same as the above, and the second `Sequence[Any]` can be used to provide any positional arguments to the plugin’s `__init__` method.
  3.  `tuple[str, Sequence[Any], Mapping[str, Any]]`: the first two fields are the same as in 2. and the third `Mapping[str, Any]` can be used to provide any keyword arguments to the plugin’s `__init__` method.
  4.  an instance of a [`B2BSynthesisPlugin`](circuit-library-synthesis-b-2-b-synthesis-plugin "qiskit_bosons.circuit.library.synthesis.B2BSynthesisPlugin"), which is used as is. This is how a plugin that is not registered through an entry point enters the pass.
