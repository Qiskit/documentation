# MergeEvolutions

<Class id="qiskit_bosons.transpiler.passes.MergeEvolutions" isDedicatedPage={true} signature="MergeEvolutions(atol=1e-12)" modifiers="class">
  Bases: [`GenericPass`](/docs/api/qiskit/qiskit.passmanager.GenericPass)\[[`DAGCircuit`](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit), [`DAGCircuit`](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit)]

  A transpilation pass merging consecutive [`Evolution`](circuit-library-evolution "qiskit_bosons.circuit.library.Evolution") gates of the same operator.

  Two evolutions under the same operator $H$ satisfy

$$
e^{-i t_2 H} e^{-i t_1 H} = e^{-i (t_1 + t_2) H},
$$

  because $H$ commutes with itself. This pass finds neighboring [`Evolution`](circuit-library-evolution "qiskit_bosons.circuit.library.Evolution") gates of the same operator and replaces them by one gate whose evolution time is the sum of theirs. The rewrite is exact, so it changes neither the simulated state nor the Trotter error of the circuit; it only removes a gate, and with it the synthesized operations that gate would have produced.

  Such neighbors arise wherever two sequences of factors meet on the same factor. Examples are the seams between the repetitions of [`BosonicCircuit.repeat()`](circuit-bosonic-circuit#repeat "qiskit_bosons.circuit.BosonicCircuit.repeat"), or between consecutive samples of [`BosonicQDrift`](circuit-library-synthesis-bosonic-q-drift "qiskit_bosons.circuit.library.synthesis.BosonicQDrift"). [`BosonicSuzukiTrotter`](circuit-library-synthesis-bosonic-suzuki-trotter "qiskit_bosons.circuit.library.synthesis.BosonicSuzukiTrotter") already fuses the seams within its own output (see [`BosonicSuzukiTrotter.merge_adjacent`](circuit-library-synthesis-bosonic-suzuki-trotter#merge_adjacent "qiskit_bosons.circuit.library.synthesis.BosonicSuzukiTrotter.merge_adjacent")); this pass is the general mechanism which also acts across gate boundaries.

  Two gates merge only when all of the following hold:

  *   they act on the identical wires, in the identical order, with nothing else in between;
  *   their operators are of the same type and equal up to [`atol`](#qiskit_bosons.transpiler.passes.MergeEvolutions.atol "qiskit_bosons.transpiler.passes.MergeEvolutions.atol") as sums of products of ladder operators, which is *stricter* than [`BosonOperator.equiv()`](operators-boson-operator#equiv "qiskit_bosons.operators.BosonOperator.equiv"), see the note below;
  *   they are either both `Evolution.atomic` or both not, and in the latter case they are decomposed by the same kind of `Evolution.synthesis` with identical settings.

  The merged gate keeps the operator, and thus the [`groups`](operators-operator-trait#groups "qiskit_bosons.operators.OperatorTrait.groups"), of the first gate of the run.

  <Admonition title="Note" type="note">
    Two operators that are [`BosonOperator.equiv()`](operators-boson-operator#equiv "qiskit_bosons.operators.BosonOperator.equiv") are not necessarily the same operator once they are truncated. Normal ordering is an identity of the untruncated Fock space, and a truncation does not preserve it: $b b^\dagger$ and $b^\dagger b + 1$ map to different matrices, which differ on the highest level. Gates whose operators are only `equiv` are therefore **not** merged, because the merged gate would no longer equal the two it replaces.
  </Admonition>

  <Admonition title="Caution" type="note">
    This is an early development prototype. Beware of changes to its interface without warning during the pre-release development of this package.
  </Admonition>

  <Admonition title="See also" type="note">
    [`Evolution`](circuit-library-evolution "qiskit_bosons.circuit.library.Evolution").
  </Admonition>

  ## Methods

  ### run

  <Function id="qiskit_bosons.transpiler.passes.MergeEvolutions.run" signature="run(dag)">
    Runs this transpilation pass.

    Collects every maximal run of consecutive [`Evolution`](circuit-library-evolution "qiskit_bosons.circuit.library.Evolution") gates on the same wires, splits it into stretches of mergeable gates and replaces each stretch of length two or more with a single [`Evolution`](circuit-library-evolution "qiskit_bosons.circuit.library.Evolution") carrying the summed time. Everything else is left untouched. The input DAG is modified in place.

    A `Barrier` interrupts a run, so the gates on either side of one are not merged. Place a barrier between two gates to keep them apart.

    **Parameters**

    **dag** ([*DAGCircuit*](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit)) – the input circuit with boson-based instructions. Only [`DAGOpNode`](/docs/api/qiskit/qiskit.dagcircuit.DAGOpNode) with [`BosonicGate`](circuit-bosonic-gate "qiskit_bosons.circuit.BosonicGate") instances as their [`op`](/docs/api/qiskit/qiskit.dagcircuit.DAGOpNode#op) are supported, plus `Barrier`, which is carried through untouched.

    **Returns**

    The output circuit which is still acting on a bosonic register.

    **Return type**

    [*DAGCircuit*](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit)
  </Function>
