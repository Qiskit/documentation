# B2BSynthesisPlugin

<Class id="qiskit_bosons.circuit.library.synthesis.B2BSynthesisPlugin" isDedicatedPage={true} signature="B2BSynthesisPlugin(*args, **kwargs)" modifiers="class">
  Bases: [`Protocol`](https://docs.python.org/3/library/typing.html#typing.Protocol)

  The protocol for plugins to the [`B2BSynthesis`](transpiler-passes-b-2-b-synthesis "qiskit_bosons.transpiler.passes.B2BSynthesis") transpiler pass.

  A plugin rewrites a gate into a [`BosonicCircuit`](circuit-bosonic-circuit "qiskit_bosons.circuit.BosonicCircuit") of *smaller* [`BosonicGate`](circuit-bosonic-gate "qiskit_bosons.circuit.BosonicGate") instances. Both sides of that rewrite live in bosonic space, so neither an occupation cutoff nor an encoding is involved: how the smaller gates are then mapped to qubits is left to the boson-to-qubit stage (see [`B2QSynthesis`](transpiler-passes-b-2-q-synthesis "qiskit_bosons.transpiler.passes.B2QSynthesis")). It is the counterpart of [`B2QSynthesisPlugin`](transpiler-passes-synthesis-b-2-q-synthesis-plugin "qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPlugin") one step earlier. Because the bosonic structure of the gate survives the rewrite, the later stage can still exploit it, in particular the [`groups`](operators-operator-trait#groups "qiskit_bosons.operators.OperatorTrait.groups") of an evolved operator (see [Group operator terms: use the operator structure](/docs/addons/qiskit-bosons/guides/grouping#grouping-explanation)).

  The gates a plugin emits should be marked [`atomic`](circuit-bosonic-gate#atomic "qiskit_bosons.circuit.BosonicGate.atomic"), and an [`Evolution`](circuit-library-evolution "qiskit_bosons.circuit.library.Evolution") among them should carry an operator with a single group, so that the boson-to-qubit stage maps every one of them whole.

  <Admonition title="Important" type="danger">
    What the circuit has to be equivalent to is specified by the *gate* a plugin is registered for, not by this protocol, and it may differ between gates: a circuit that implements the same unitary is the common case (up to the error of the method for an [`Evolution`](circuit-library-evolution "qiskit_bosons.circuit.library.Evolution"), and on the untruncated Fock space for a [`ModeRotation`](circuit-library-mode-rotation "qiskit_bosons.circuit.library.ModeRotation")), but a gate may settle for less. Consult the documentation of the gate whose method you implement, and document any such caveat there.
  </Admonition>

  <Admonition title="Important" type="danger">
    This boson-to-boson step is **optional**. A gate can be handed to the boson-to-qubit stage whole, where a plugin of that stage registered for it can map it directly. Where an approximation is involved at both levels, the accuracy of the result is governed by the weaker of the two.
  </Admonition>

  <Admonition title="Note" type="note">
    Qiskit’s [`EvolutionSynthesis`](/docs/api/qiskit/qiskit.synthesis.EvolutionSynthesis) is the closest analogue, but it belongs to the qubit layer: it synthesizes a [`PauliEvolutionGate`](/docs/api/qiskit/qiskit.circuit.library.PauliEvolutionGate) into a [`QuantumCircuit`](/docs/api/qiskit/qiskit.circuit.QuantumCircuit), after the operator has already been mapped and the occupation truncation has been applied. A bosonic synthesis, by contrast, carries no cutoff.
  </Admonition>
