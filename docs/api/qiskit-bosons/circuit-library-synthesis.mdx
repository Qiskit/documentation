# Circuit Library Synthesis (B2B)

This module provides the synthesis methods with which a bosonic gate is broken down into a [`BosonicCircuit`](/docs/api/qiskit-bosons/circuit-bosonic-circuit#qiskit_bosons.circuit.BosonicCircuit "qiskit_bosons.circuit.BosonicCircuit") of smaller bosonic gates. Pass one to the gate’s `synthesis` argument to choose how it gets decomposed. For an [`Evolution`](/docs/api/qiskit-bosons/circuit-library-evolution#qiskit_bosons.circuit.library.Evolution "qiskit_bosons.circuit.library.Evolution") gate that is its time evolution:

```python
Evolution(num_modes, operator, time=1.0, synthesis=BosonicLieTrotter())
```

or choose them for a whole circuit at once with the [`B2BSynthesis`](/docs/api/qiskit-bosons/transpiler-passes-b-2-b-synthesis#qiskit_bosons.transpiler.passes.B2BSynthesis "qiskit_bosons.transpiler.passes.B2BSynthesis") transpiler pass. Any class with a `synthesize(gate)` method can leverage a plugin (see [`B2BSynthesisPlugin`](/docs/api/qiskit-bosons/circuit-library-synthesis-b-2-b-synthesis-plugin#qiskit_bosons.circuit.library.synthesis.B2BSynthesisPlugin "qiskit_bosons.circuit.library.synthesis.B2BSynthesisPlugin")), and the ones registered under the `qiskit_bosons.circuit.synthesis` entry point are available by name through the [`B2BSynthesisPluginManager`](/docs/api/qiskit-bosons/circuit-library-synthesis-b-2-b-synthesis-plugin-manager#qiskit_bosons.circuit.library.synthesis.B2BSynthesisPluginManager "qiskit_bosons.circuit.library.synthesis.B2BSynthesisPluginManager").

Both sides of this rewrite live in bosonic space, so these methods can exploit the [`groups`](/docs/api/qiskit-bosons/operators-operator-trait#qiskit_bosons.operators.OperatorTrait.groups "qiskit_bosons.operators.OperatorTrait.groups") of the evolved operator (see [Group operator terms: use the operator structure](/docs/addons/qiskit-bosons/guides/grouping#grouping-explanation)) – unlike the boson-to-qubit synthesis that follows, which only sees the mapped operator, where the grouping is no longer available. That is what lets the *outer* Trotter error between non-commuting groups be reduced by a higher order or more repetitions, which a product formula handed to `MapperFnEvolutionSynthesis` cannot do.

A [`ModeRotation`](/docs/api/qiskit-bosons/circuit-library-mode-rotation#qiskit_bosons.circuit.library.ModeRotation "qiskit_bosons.circuit.library.ModeRotation") gate is broken down the same way, into [`Evolution`](/docs/api/qiskit-bosons/circuit-library-evolution#qiskit_bosons.circuit.library.Evolution "qiskit_bosons.circuit.library.Evolution") gates, one for every two-mode rotation and single-mode phase of its mesh. Its `synthesis` is `None` by default, which leaves the gate whole:

```python
ModeRotation(unitary, synthesis=BosonicClementsDecomposition())
```

<Admonition title="Important" type="danger">
  This boson-to-boson step is **optional**. An [`Evolution`](/docs/api/qiskit-bosons/circuit-library-evolution#qiskit_bosons.circuit.library.Evolution "qiskit_bosons.circuit.library.Evolution") gate can be handed straight to the boson-to-qubit stage regardless of how many terms its operator holds, and so can a [`ModeRotation`](/docs/api/qiskit-bosons/circuit-library-mode-rotation#qiskit_bosons.circuit.library.ModeRotation "qiskit_bosons.circuit.library.ModeRotation"), given a plugin registered for it. Decomposing in bosonic space first is a choice, taken to obtain cheaper factors or to expose structure that the later stage can exploit.
</Admonition>
