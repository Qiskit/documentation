# B2BSynthesisPluginManager

<Class id="qiskit_bosons.circuit.library.synthesis.B2BSynthesisPluginManager" isDedicatedPage={true} signature="B2BSynthesisPluginManager" modifiers="class">
  Bases: [`object`](https://docs.python.org/3/builtins/functions.html#object)

  A simple manager of the installed boson-to-boson synthesis plugins.

  All plugins that are registered under the `qiskit_bosons.circuit.synthesis` [entry-point](https://setuptools.pypa.io/en/latest/userguide/entry_point.html) will be available to this class and get exposed by the [`plugins`](#qiskit_bosons.circuit.library.synthesis.B2BSynthesisPluginManager.plugins "qiskit_bosons.circuit.library.synthesis.B2BSynthesisPluginManager.plugins") attribute. The name of an entry point is the name of the gate class followed by the name of the method, separated by a dot, for example `ModeRotation.Clements`. Below is the table from the `pyproject.toml` of this package itself:

  ```toml
  [project.entry-points."qiskit_bosons.circuit.synthesis"]
  "Evolution.LieTrotter" = "qiskit_bosons.circuit.library.synthesis:BosonicLieTrotter"
  "Evolution.SuzukiTrotter" = "qiskit_bosons.circuit.library.synthesis:BosonicSuzukiTrotter"
  "Evolution.QDrift" = "qiskit_bosons.circuit.library.synthesis:BosonicQDrift"
  "ModeRotation.Clements" = "qiskit_bosons.circuit.library.synthesis:BosonicClementsDecomposition"
  ```

  An overview of all builtin plugins is given [here](/docs/api/qiskit-bosons/circuit-library-synthesis#builtin-b2b-synthesis-plugins).

  ## Attributes

  ### plugins

  <Attribute id="qiskit_bosons.circuit.library.synthesis.B2BSynthesisPluginManager.plugins">
    Type: [`dict`](https://docs.python.org/3/builtins/stdtypes.html#dict)\[[`str`](https://docs.python.org/3/builtins/stdtypes.html#str), [`list`](https://docs.python.org/3/builtins/stdtypes.html#list)\[[`str`](https://docs.python.org/3/builtins/stdtypes.html#str)]]

    A dictionary mapping gate names to their synthesis methods.

    The keys of this dictionary are names of [`BosonicGate`](circuit-bosonic-gate "qiskit_bosons.circuit.BosonicGate") classes. The values are the list of installed [`B2BSynthesisPlugin`](circuit-library-synthesis-b-2-b-synthesis-plugin "qiskit_bosons.circuit.library.synthesis.B2BSynthesisPlugin") methods that may be used to synthesize the instances of that particular gate.
  </Attribute>
