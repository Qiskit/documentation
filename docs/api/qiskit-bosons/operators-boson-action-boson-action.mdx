# BosonAction

<Attribute id="qiskit_bosons.operators.boson_action.BosonAction" isDedicatedPage={true}>
  A bosonic creation or annihilation action.

  A 2-tuple `(action, mode)` where `action` is `True` for a creation and `False` for an annihilation action, and `mode` is the bosonic mode index on which to act.
