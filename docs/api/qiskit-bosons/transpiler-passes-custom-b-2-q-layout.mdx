# CustomB2QLayout

<Class id="qiskit_bosons.transpiler.passes.CustomB2QLayout" isDedicatedPage={true} signature="CustomB2QLayout(layout)" modifiers="class">
  Bases: [`GenericPass`](/docs/api/qiskit/qiskit.passmanager.GenericPass)\[[`DAGCircuit`](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit), [`DAGCircuit`](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit)]

  Sets the user-provided [`B2QLayout`](transpiler-b-2-q-layout "qiskit_bosons.transpiler.B2QLayout") in the transpiler.

  This pass simply populates the `b2q_layout` field of the [`property_set`](/docs/api/qiskit/qiskit.passmanager.PassManagerState#property_set), with the value of [`layout`](#qiskit_bosons.transpiler.passes.CustomB2QLayout.layout "qiskit_bosons.transpiler.passes.CustomB2QLayout.layout").

  <Admonition title="Note" type="note">
    It is the user’s responsibility to ensure that subsequently used transpilation passes (and plugins) are configured to adhere to this [`B2QLayout`](transpiler-b-2-q-layout "qiskit_bosons.transpiler.B2QLayout") correctly.
  </Admonition>

  Initializing this transpiler pass can be done with the arguments listed below.

  **Parameters**

  **layout** ([*B2QLayout*](transpiler-b-2-q-layout "qiskit_bosons.transpiler.B2QLayout")) – the custom `b2q_layout` to use.
