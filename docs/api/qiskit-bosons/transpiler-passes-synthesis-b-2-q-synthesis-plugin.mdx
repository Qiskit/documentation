# B2QSynthesisPlugin

  Bases: [`Protocol`](https://docs.python.org/3/library/typing.html#typing.Protocol)

  ## Methods

  ### run

  <Function id="qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPlugin.run" signature="run(in_node, out_dag, *, b2q_layout)">
    Translates the provided boson-based circuit instruction to a qubit-based one.

    **Parameters**

    *   **in\_node** ([*DAGOpNode*](/docs/api/qiskit/qiskit.dagcircuit.DAGOpNode)) – a boson-based circuit instruction stored in a [`DAGOpNode`](/docs/api/qiskit/qiskit.dagcircuit.DAGOpNode). Specifically, this guarantees that [`op`](/docs/api/qiskit/qiskit.dagcircuit.DAGOpNode#op) is of type [`BosonicGate`](circuit-bosonic-gate "qiskit_bosons.circuit.BosonicGate").
    *   **out\_dag** ([*DAGCircuit*](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit)) – the qubit-based [`DAGCircuit`](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit) into which this plugin must insert the translated circuit instruction.
    *   **b2q\_layout** ([*dict*](https://docs.python.org/3/builtins/stdtypes.html#dict)*\[*[*QuantumRegister*](/docs/api/qiskit/circuit#qiskit.circuit.QuantumRegister)*,* [*QuantumRegister*](/docs/api/qiskit/circuit#qiskit.circuit.QuantumRegister)*]*) – the [`B2QLayout`](transpiler-b-2-q-layout "qiskit_bosons.transpiler.B2QLayout") setting that is global to the transpilation process. It is the plugin’s responsibility to respect this mapping of [`BosonicRegister`](circuit-bosonic-register "qiskit_bosons.circuit.BosonicRegister") to [`QuantumRegister`](/docs/api/qiskit/circuit#qiskit.circuit.QuantumRegister).

    **Return type**

    None
  </Function>
