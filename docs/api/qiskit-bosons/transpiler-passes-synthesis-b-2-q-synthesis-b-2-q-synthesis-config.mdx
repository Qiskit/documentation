# B2QSynthesisConfig

<Attribute id="qiskit_bosons.transpiler.passes.synthesis.b2q_synthesis.B2QSynthesisConfig" isDedicatedPage={true}>
  The dictionary type used to configure the [`B2QSynthesis.methods`](transpiler-passes-b-2-q-synthesis#methods "qiskit_bosons.transpiler.passes.B2QSynthesis.methods").

  The keys of this dictionary must be names of [`BosonicGate`](circuit-bosonic-gate "qiskit_bosons.circuit.BosonicGate") circuit instructions. The values can be one of four types:

  1.  `str`: the simplest scenario simply specifies the name of the plugin method to use for the corresponding key in this dictionary. The plugin is extracted from the [`B2QSynthesisPluginManager`](transpiler-passes-synthesis-b-2-q-synthesis-plugin-manager "qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPluginManager") and its `__init__` method may **not** require any arguments.
  2.  `tuple[str, Sequence[Any]]`: the first `str` is the same as the above, and the second `Sequence[Any]` can be used to provide any positional arguments to the plugin’s `__init__` method.
  3.  `tuple[str, Sequence[Any], Mapping[str, Any]]`: the first two fields are the same as in 2. and the third `Mapping[str, Any]` can be used to provide any keyword arguments to the plugin’s `__init__` method.
  4.  an instance of a [`B2QSynthesisPlugin`](transpiler-passes-synthesis-b-2-q-synthesis-plugin "qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPlugin"), which is used as is. This is how a plugin that is not registered through an entry point enters the pass.
