# QDriftSampler

<Class id="qiskit_bosons.circuit.library.synthesis.QDriftSampler" isDedicatedPage={true} signature="QDriftSampler(gate, num_terms, weights, rng)" modifiers="class">
  Bases: [`object`](https://docs.python.org/3/builtins/functions.html#object)

  The draws of the qDRIFT protocol for one [`Evolution`](circuit-library-evolution "qiskit_bosons.circuit.library.Evolution") gate.

  This is what [`BosonicQDrift.sampler()`](circuit-library-synthesis-bosonic-q-drift#sampler "qiskit_bosons.circuit.library.synthesis.BosonicQDrift.sampler") returns. It holds the distribution derived from the gate, and exists so that a caller that needs to look at each draw can take them one at a time, whereas [`BosonicQDrift.synthesize()`](circuit-library-synthesis-bosonic-q-drift#synthesize "qiskit_bosons.circuit.library.synthesis.BosonicQDrift.synthesize") takes them all at once.

  Initializing a sampler can be done with the arguments below.

  **Parameters**

  *   **gate** ([*Evolution*](circuit-library-evolution "qiskit_bosons.circuit.library.Evolution")) – the gate to sample.
  *   **num\_terms** ([*int*](https://docs.python.org/3/builtins/functions.html#int)) – the number of gates the whole sample holds.
  *   **weights** (*np.ndarray | None*) – the sampling weights, or `None` to derive them from the operator of `gate`.
  *   **rng** (*np.random.Generator*) – the random number generator to draw from.

  **Raises**

  [**ValueError**](https://docs.python.org/3/builtins/exceptions.html#ValueError) – if `weights` does not hold one entry per group (or term) of the operator.
