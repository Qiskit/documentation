# Transpiler Pass Synthesis (B2Q)

The [`B2QSynthesis`](/docs/api/qiskit-bosons/transpiler-passes-b-2-q-synthesis#qiskit_bosons.transpiler.passes.B2QSynthesis "qiskit_bosons.transpiler.passes.B2QSynthesis") transpiler pass exposes a plugin interface (see [`B2QSynthesisPlugin`](/docs/api/qiskit-bosons/transpiler-passes-synthesis-b-2-q-synthesis-plugin#qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPlugin "qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPlugin")) through which implementations for mapping boson-based instructions to qubit-based ones can be registered. It is the counterpart of the boson-to-boson synthesis that the [`B2BSynthesis`](/docs/api/qiskit-bosons/transpiler-passes-b-2-b-synthesis#qiskit_bosons.transpiler.passes.B2BSynthesis "qiskit_bosons.transpiler.passes.B2BSynthesis") pass performs one stage earlier (see [`synthesis`](circuit-library-synthesis#module-qiskit_bosons.circuit.library.synthesis "qiskit_bosons.circuit.library.synthesis")).

The available plugins are managed by the [`B2QSynthesisPluginManager`](/docs/api/qiskit-bosons/transpiler-passes-synthesis-b-2-q-synthesis-plugin-manager#qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPluginManager "qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPluginManager"). Choosing the right combination of synthesis plugins is crucial and the [`B2QSynthesis`](/docs/api/qiskit-bosons/transpiler-passes-b-2-q-synthesis#qiskit_bosons.transpiler.passes.B2QSynthesis "qiskit_bosons.transpiler.passes.B2QSynthesis") transpilation pass does **not** have any default plugins defined! For this, refer to the transpiler [`presets`](transpiler-presets#module-qiskit_bosons.transpiler.presets "qiskit_bosons.transpiler.presets").

## Builtin plugins

The plugins to use at runtime have to be registered in the [`B2QSynthesis.methods`](/docs/api/qiskit-bosons/transpiler-passes-b-2-q-synthesis#qiskit_bosons.transpiler.passes.B2QSynthesis.methods "qiskit_bosons.transpiler.passes.B2QSynthesis.methods") attribute. This can be done easily through the `config` argument of [`B2QSynthesis`](/docs/api/qiskit-bosons/transpiler-passes-b-2-q-synthesis#qiskit_bosons.transpiler.passes.B2QSynthesis "qiskit_bosons.transpiler.passes.B2QSynthesis") which specifies the plugins to use from the [`B2QSynthesisPluginManager`](/docs/api/qiskit-bosons/transpiler-passes-synthesis-b-2-q-synthesis-plugin-manager#qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPluginManager "qiskit_bosons.transpiler.passes.synthesis.B2QSynthesisPluginManager") or it can be done manually by writing into [`B2QSynthesis.methods`](/docs/api/qiskit-bosons/transpiler-passes-b-2-q-synthesis#qiskit_bosons.transpiler.passes.B2QSynthesis.methods "qiskit_bosons.transpiler.passes.B2QSynthesis.methods") directly.

There is one plugin per [`BosonicGate`](/docs/api/qiskit-bosons/circuit-bosonic-gate#qiskit_bosons.circuit.BosonicGate "qiskit_bosons.circuit.BosonicGate") type. Each is handed the gate and the global [`B2QLayout`](/docs/api/qiskit-bosons/transpiler-b-2-q-layout#qiskit_bosons.transpiler.B2QLayout "qiskit_bosons.transpiler.B2QLayout"), and inserts the equivalent qubit-based instructions.

The builtin plugins are where the boson-to-qubit **encoding** and the **truncation** enter the pipeline: the plugins taking a `mapper_fn` do so through the mapper they wrap, and the `InitializeModes` plugin through the [`LevelSpec`](/docs/api/qiskit-bosons/mappers-level-spec#qiskit_bosons.mappers.LevelSpec "qiskit_bosons.mappers.LevelSpec") it is given. This is the point of deferring the encoding to transpile time: the bosonic circuit upstream of this stage is independent of both choices.

## Additional helper functions

The Pauli term order that a mapper function produces is preserved through synthesis, since a product formula synthesizes the terms in the order it receives them. These adapters wrap a mapper function to choose that order:

|                                                                                                                                                                                                        |                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| [`group_wise`](/docs/api/qiskit-bosons/transpiler-passes-synthesis-group-wise#qiskit_bosons.transpiler.passes.synthesis.group_wise "qiskit_bosons.transpiler.passes.synthesis.group_wise")(mapper\_fn) | Wraps a mapper function so that it maps an operator one group at a time. |
| [`simplify`](/docs/api/qiskit-bosons/transpiler-passes-synthesis-simplify#qiskit_bosons.transpiler.passes.synthesis.simplify "qiskit_bosons.transpiler.passes.synthesis.simplify")(mapper\_fn)         | Wraps a mapper function so that it simplifies the operator it returns.   |
