# API Reference

Samplomatic

## Functions

|                                                              |                                                                      |
| ------------------------------------------------------------ | -------------------------------------------------------------------- |
| [`build`](auto/build "samplomatic.build")(circuit\[, debug]) | Build a circuit template and samplex for the given boxed-up circuit. |

## Classes

|                                                                                                     |                                                            |
| --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| [`ChangeBasis`](auto/change-basis "samplomatic.ChangeBasis")(\[decomposition, mode, ref, dressing]) | Directive to add basis changing gates.                     |
| [`InjectNoise`](auto/inject-noise "samplomatic.InjectNoise")(ref\[, modifier\_ref, site])           | Directive to inject noise into a `box` instruction.        |
| [`Tag`](auto/tag "samplomatic.Tag")(\[ref])                                                         | Annotation to tag and instruction with a string reference. |
| [`Twirl`](auto/twirl "samplomatic.Twirl")(\[group, dressing, decomposition])                        | Directive to twirl the contents of a `box` instruction.    |
