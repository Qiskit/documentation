  A node that we want to add to the graph, but not yet.

  The node is only added when we ask for its [`node_idx`](#samplomatic.graph_utils.NodeCandidate.node_idx "samplomatic.graph_utils.NodeCandidate.node_idx") in the graph.

  **Parameters**

  *   **graph** – The graph to add the node to.
  *   **node** – The node data for the node to add.
