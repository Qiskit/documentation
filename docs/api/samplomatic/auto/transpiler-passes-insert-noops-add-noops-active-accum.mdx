# AddNoopsActiveAccum

<Class id="samplomatic.transpiler.passes.insert_noops.AddNoopsActiveAccum" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/transpiler/passes/insert_noops/add_noops_active_accum.py#L20-L54" signature="samplomatic.transpiler.passes.insert_noops.AddNoopsActiveAccum(*args, **kwargs)" modifiers="class">
  Bases: [`TransformationPass`](/docs/api/qiskit/qiskit.transpiler.TransformationPass)

  Expand each box to any qubits that have been marked as active so far in the circuit.

  This pass leaves non-box operations as-is, but boxes are modified to span any qubits that are part of a previous box.
