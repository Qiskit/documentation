# FrozenDict

<Class id="samplomatic.utils.FrozenDict" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/utils/frozen_dict.py#L20-L110" signature="samplomatic.utils.FrozenDict(*args, **kwargs)" modifiers="class">
  Bases: [`Mapping`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Mapping)

  An immutable and hashable dictionary-like mapping.

  Keys and values must be hashable. Views onto keys, items, and values are read-only and preserve insertion order. Standard operands like `|` are supported, but return copies when necessary.
