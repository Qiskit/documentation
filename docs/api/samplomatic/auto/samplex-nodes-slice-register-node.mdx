# SliceRegisterNode

<Class id="samplomatic.samplex.nodes.SliceRegisterNode" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplex/nodes/slice_register_node.py#L26-L144" signature="samplomatic.samplex.nodes.SliceRegisterNode(input_type: VirtualType, output_type: VirtualType, input_register_name: str, output_register_name: str, slice_idxs: slice | Sequence[int], force_copy: bool = False)" modifiers="class">
  Bases: [`EvaluationNode`](samplex-nodes-evaluation-node "samplomatic.samplex.nodes.evaluation_node.EvaluationNode")

  A node to slice a register.

  <Admonition title="Note" type="note">
    Slicing of a register can alternatively be done using a [`CombineRegistersNode`](samplex-nodes-combine-registers-node "samplomatic.samplex.nodes.CombineRegistersNode"), providing `operands` of length `1`. However, using [`SliceRegisterNode`](#samplomatic.samplex.nodes.SliceRegisterNode "samplomatic.samplex.nodes.SliceRegisterNode") is recommended because its [`evaluate()`](#samplomatic.samplex.nodes.SliceRegisterNode.evaluate "samplomatic.samplex.nodes.SliceRegisterNode.evaluate") method is optimized for slicing a single register.
  </Admonition>

  **Parameters**

  *   **input\_type** – The type of the input register.
  *   **output\_type** – The type of the output register.
  *   **input\_register\_name** – The name of the input register.
  *   **output\_register\_name** – The name of the output register.
  *   **slice\_idxs** – The indices used to slice the register.
  *   **force\_copy** – Whether or not to force output register to be a copy instead of a view of the input register.

  **Raises**

  [**SamplexConstructionError**](exceptions-samplex-construction-error "samplomatic.exceptions.SamplexConstructionError") – If `slice_idxs` has the wrong shape.
