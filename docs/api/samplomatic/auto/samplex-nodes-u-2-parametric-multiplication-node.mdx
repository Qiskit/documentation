# U2ParametricMultiplicationNode

<Class id="samplomatic.samplex.nodes.U2ParametricMultiplicationNode" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/samplex/nodes/u2_param_multiplication_node.py#L27-L93" signature="samplomatic.samplex.nodes.U2ParametricMultiplicationNode(operand: Literal['rz', 'rx'], register_name: str, param_idxs: list[int])" modifiers="class">
  Bases: [`EvaluationNode`](samplex-nodes-evaluation-node "samplomatic.samplex.nodes.evaluation_node.EvaluationNode")

  Abstract parent node for nodes doing multiplication on a [`U2Register`](virtual-registers-u-2-register "samplomatic.virtual_registers.U2Register").

  The node stores a parametric representation of a one-qubit gate or gates from the original circuit to perform multiplication on a registry.

  Limited to the gates `rz` or `rx`, and all gates within the node are of the same type.

  **Parameters**

  *   **operand** – The gate type, given as a string.
  *   **register\_name** – The name of the register the operation is applied to.
  *   **param\_idxs** – List of `ParamIndex` for the parameter expressions specifying the gate arguments. List order must match the order subsystems in the registry.

  **Raises**

  *   [**SamplexConstructionError**](exceptions-samplex-construction-error "samplomatic.exceptions.SamplexConstructionError") – if param\_idxs is empty.
  *   [**SamplexConstructionError**](exceptions-samplex-construction-error "samplomatic.exceptions.SamplexConstructionError") – if operand is not `rz` or `rx`.
