  ### free\_dimensions

  <Attribute id="samplomatic.tensor_interface.Specification.free_dimensions">
    Named dimensions whose sizes are free until an interface value binds their value.

    Within a [`TensorInterface`](tensor-interface-tensor-interface "samplomatic.tensor_interface.TensorInterface"), all free dimensions of the same name must be consistently bound. This allows specification of dimensions of values that can be arbitrary, and that are only resolved once bound to an interface.
  </Attribute>

  ### name

  <Attribute id="samplomatic.tensor_interface.Specification.name">

  ### num\_bytes

  <Attribute id="samplomatic.tensor_interface.Specification.num_bytes">
    The number of bytes required to represent data for this specification.

    Implementations of this attribute should not be overly concerned with accounting for memory required, say, for builtin Python container objects. They should be more interested in the large data limit where memory is dominated by sources like NumPy buffers.

    If the specification has [`free_dimensions`](#samplomatic.tensor_interface.Specification.free_dimensions "samplomatic.tensor_interface.Specification.free_dimensions"), implementations should return the number of bytes per unit of each free dimension. For example, if the specification has a free dimension `"n"` and requires `8 * n` bytes, this property should return `8`.
  </Attribute>
