# AddNoopsAll

<Class id="samplomatic.transpiler.passes.insert_noops.AddNoopsAll" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/transpiler/passes/insert_noops/add_noops_all.py#L21-L29" signature="samplomatic.transpiler.passes.insert_noops.AddNoopsAll(*args, **kwargs)" modifiers="class">
  Bases: [`TransformationPass`](/docs/api/qiskit/qiskit.transpiler.TransformationPass)

  Expand boxes to all qubits contained in a circuit.

  This pass leaves non-box operations as-is, but boxes are modified to span all the qubits as defined when initializing the QuantumCircuit object.
