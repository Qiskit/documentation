# ParameterExpressionTable

<Class id="samplomatic.samplex.ParameterExpressionTable" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/samplex/parameter_expression_table.py#L31-L150" signature="samplomatic.samplex.ParameterExpressionTable" modifiers="class">
  Bases: [`object`](https://docs.python.org/3/builtins/functions.html#object)

  Evaluates a list of parameter expressions given a list of parameter values.

  An instance of this class owns an ordered list of $M$ `ParameterExpression`s that together implicitly specify an ordered list of distinct $N$ `Parameter`s. Because parameter expressions can involve multiple parameters, because distinct parameter expressions can reference the same parameters, and because parameter expressions that are completely bound contain no parameters, there is in general no relationship between $N$ and $M$. However, $N=M$ in the common special case that all parameter expressions are just, in fact, unique parameters.

  The [`evaluate()`](#samplomatic.samplex.ParameterExpressionTable.evaluate "samplomatic.samplex.ParameterExpressionTable.evaluate") method accepts $N$ parameter values, and returns numeric values for each of the $M$ parameter expressions.

  This class can be used as a shim for tools that want to accept parameter values but use expressions of them without the tedious responsibilities usually attached.

  ### evaluate

  <Function id="samplomatic.samplex.ParameterExpressionTable.evaluate" github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/samplex/parameter_expression_table.py#L103-L143" signature="evaluate(parameter_values: Sequence[float] | dict[Parameter, float], indices: Sequence[int] | None = None) → ndarray">
    Return numeric values for the table’s expressions.

    **Parameters**

    *   **parameter\_values** – The parameter values, either as a map from parameters to their values, or just the values in parameter-sorted order (see [`parameters`](#samplomatic.samplex.ParameterExpressionTable.parameters "samplomatic.samplex.ParameterExpressionTable.parameters")).
    *   **indices** – An optional sequence of expression indices to evaluate. When `None`, all expressions are evaluated in order. When provided, only the expressions at the given indices are evaluated, in the given order, so `len(returned_array) == len(indices)`.

    **Returns**

    An array of evaluated expressions.

    **Raises**

    [**ParameterError**](exceptions-parameter-error "samplomatic.exceptions.ParameterError") – If the correct number of parameters is not supplied, or if some expression requires a value for a parameter that was not provided.
  </Function>
