# AddNoopsActiveCircuit

<Class id="samplomatic.transpiler.passes.insert_noops.AddNoopsActiveCircuit" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/transpiler/passes/insert_noops/add_noops_active_circuit.py#L22-L32" signature="samplomatic.transpiler.passes.insert_noops.AddNoopsActiveCircuit(*args, **kwargs)" modifiers="class">
  Bases: [`TransformationPass`](/docs/api/qiskit/qiskit.transpiler.TransformationPass)

  Expand boxes to any qubit marked as active at any point in the circuit.

  This pass leaves non-box operations as-is, but boxes are modified to span the original qubits, original clbits, and any qubits not already included in the original qubits which have been marked as active at any other point in the circuit.
