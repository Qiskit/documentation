# ConversionNode

<Class id="samplomatic.samplex.nodes.ConversionNode" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/samplex/nodes/conversion_node.py#L21-L114" signature="samplomatic.samplex.nodes.ConversionNode(existing_name: str, existing_type: VirtualType, new_name: str, new_type: VirtualType, num_subsystems: int, remove_existing: bool)" modifiers="class">
  Bases: [`EvaluationNode`](samplex-nodes-evaluation-node "samplomatic.samplex.nodes.evaluation_node.EvaluationNode")

  Converts a node from one type to another.

  **Parameters**

  *   **existing\_name** – The name of the register to convert.
  *   **existing\_type** – The type of the register to convert.
  *   **new\_name** – The name of the the converted register, possibly equal to `existing_name`.
  *   **new\_type** – The type to convert to.
  *   **num\_subsystems** – The number of subsystems in the register to convert.
  *   **remove\_existing** – Whether to remove the existing register following conversion.

  **Raises**

  [**SamplexConstructionError**](exceptions-samplex-construction-error "samplomatic.exceptions.SamplexConstructionError") – If the names are the same, and `remove_existing` is true.
