# TensorInterface

<Class id="samplomatic.tensor_interface.TensorInterface" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/tensor_interface.py#L304-L604" signature="samplomatic.tensor_interface.TensorInterface(specs: Iterable[Specification])" modifiers="class">
  Bases: [`MutableMapping`](https://docs.python.org/3/library/collections.abc.html#collections.abc.MutableMapping)

  An interface described by strict value type specifications, with a focus on tensor values.

  This object implements the mapping protocol against data that is present; if a possible value type has a [`Specification`](tensor-interface-specification "samplomatic.tensor_interface.Specification"), it is not reported as being present (i.e. `"name" in interface`) until a value has been assigned to it. Assigning to a key without a specification, or an invalid value to a specified key, will raise an error.

  **Parameters**

  **specs** – An iterable of specificaitons for the allowed data in this interface.

  ### shape

  <Attribute id="samplomatic.tensor_interface.TensorInterface.shape">
    The shape of this interface broadcasted over all present broadcastable tensor values.

    This shape does not include the native shapes of any particular tensor value. For example, if some broadastable value has shape `(4, 5, 6, 7)` and the associated tensor specification has shape `(6, 7)`, then this value naturally contributes a shape of `(4, 5)` to this interface. Consequently, the shape here will always be `()` for an interface with no broadcastable specifications.
  </Attribute>

  ### bind

  <Function id="samplomatic.tensor_interface.TensorInterface.bind" github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/tensor_interface.py#L478-L522" signature="bind(**kwargs: Mapping[str, Any]) → Self">
    Bind data to this interface.

    A tensor interface is a flat data structure mapping names to values, where the values must conform to constraints specifed by the [`specs`](#samplomatic.tensor_interface.TensorInterface.specs "samplomatic.tensor_interface.TensorInterface.specs").

    ```python
    >>> from samplomatic.tensor_interface import TensorSpecification, TensorInterface
    >>> import numpy as np
    >>>
    >>> interface = TensorInterface([
    ...     TensorSpecification("foo.bar", (2, 3), np.float64),
    ...     TensorSpecification("x", (15,), np.int64),
    ...     TensorSpecification("y", (4,), np.float32)
    ... ])
    >>>
    >>> # bind a single value
    >>> interface.bind(x=np.arange(15), y=np.linspace(0, 1, 4))
    TensorInterface(...)
    >>>
    >>> # bind a value that has a "."-separated name
    >>> interface.bind(foo={"bar": np.zeros((2, 3))})
    TensorInterface(...)
    >>>
    >>> # alternatively, items can be set directly
    >>> interface["foo.bar"] = np.ones((2, 3))
    >>> interface["y"] = [2.1, 2.2, 2.3, 2.4]
    ```

    **Parameters**

    **\*\*kwargs** – Key-value data to bind.

    **Raises**

    [**ValueError**](https://docs.python.org/3/builtins/exceptions.html#ValueError) – If a specification not present in this interface is in `kwargs`.

    **Returns**

    This interface.
  </Function>

  ### num\_bytes

  <Function id="samplomatic.tensor_interface.TensorInterface.num_bytes" github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/tensor_interface.py#L373-L402" signature="num_bytes(**dimensions: int) → int">
    Return the total number of bytes required to represent all data in this interface.

    This sums [`num_bytes`](tensor-interface-specification#num_bytes "samplomatic.tensor_interface.Specification.num_bytes") over all specifications, multiplied by the product of all free dimensions that each specification depends on.

    This estimate is not overly concerned with accounting for memory required, say, for builtin Python container objects. It is more interested in the large data limit where memory is dominated by sources like NumPy buffers.

    **Parameters**

    **\*\*dimensions** – Values for free dimensions. These override any already-bound dimensions.

    **Raises**

    [**ValueError**](https://docs.python.org/3/builtins/exceptions.html#ValueError) – If any free dimensions are not specified.
  </Function>
