# PauliPastCliffordNode

<Class id="samplomatic.samplex.nodes.PauliPastCliffordNode" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplex/nodes/pauli_past_clifford_node.py#L106-L182" signature="samplomatic.samplex.nodes.PauliPastCliffordNode(op_name: str, register_name: str, subsystem_idxs: Sequence[Sequence[int]], *, lookup_table: ndarray | None = None)" modifiers="class">
  Bases: [`EvaluationNode`](samplex-nodes-evaluation-node "samplomatic.samplex.nodes.evaluation_node.EvaluationNode")

  A node that propagates a Pauli register past a Clifford gate.

  **Parameters**

  *   **op\_name** – The name of the Clifford gate.
  *   **register\_name** – The name of the Pauli register to propagate.
  *   **subsystem\_idxs** – The subsystems in the register. The expected format is that of a collection of subsystems of the same size, i.e., that of a 2D array where the left-most axes is over subsystems and the right-most axes is over qubits.
