# ChangeBasisNode

<Class id="samplomatic.samplex.nodes.ChangeBasisNode" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/samplex/nodes/change_basis_node.py#L113-L162" signature="samplomatic.samplex.nodes.ChangeBasisNode(register_name: str, basis_change: BasisChange, basis_ref: str, num_subsystems: int)" modifiers="class">
  Bases: [`SamplingNode`](samplex-nodes-sampling-node "samplomatic.samplex.nodes.sampling_node.SamplingNode")

  A node that instantiates a basis changing virtual register for a given measurement.

  **Parameters**

  *   **register\_name** – The name of the register to instantiate.
  *   **basis\_change** – The basis change to implement.
  *   **basis\_ref** – Unique identifier of the basis to use.
  *   **num\_subsystems** – The number of subsystems this node generates gates for.
