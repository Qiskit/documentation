# UniformLocalC1

<Class id="samplomatic.distributions.UniformLocalC1" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/distributions/uniform_local_c1.py#L22-L89" signature="samplomatic.distributions.UniformLocalC1(num_subsystems: int, gate_name: str, *, lookup_table: ndarray | None = None)" modifiers="class">
  Bases: [`Distribution`](distributions-distribution "samplomatic.distributions.distribution.Distribution")

  The uniform distribution over C1⊗C1 elements that stay local and C1 under conjugation.

  For each pair of consecutive subsystems, independently draws a pair `(c0, c1)` uniformly from the set of C1⊗C1 elements that remain factorized as C1⊗C1 after conjugation by the specified two-qubit gate.

  **Parameters**

  *   **num\_subsystems** – The number of subsystems this distribution samples. Must be even.
  *   **gate\_name** – A two-qubit gate name whose conjugation table appears in `LOCAL_C1_PROPAGATE_LOOKUP_TABLES`.
