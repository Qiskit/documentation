# strip\_annotations

<Function id="samplomatic.utils.strip_annotations" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/utils/map_annotations.py#L63-L85" signature="samplomatic.utils.strip_annotations(circuit: QuantumCircuit) → QuantumCircuit">
  Return a new circuit with all annotations removed from every box.

  **Parameters**

  **circuit** – The circuit whose box annotations to strip.

  **Returns**

  A new circuit with empty annotation lists on every box.

  ```python
  from qiskit.circuit import QuantumCircuit
  from samplomatic import Twirl
  from samplomatic.utils import strip_annotations

  circuit = QuantumCircuit(2)
  with circuit.box([Twirl()]):
      circuit.cx(0, 1)

  bare = strip_annotations(circuit)
  ```
