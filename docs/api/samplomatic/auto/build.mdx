# samplomatic.build

<Function id="samplomatic.build" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/builders/build.py#L97-L115" signature="samplomatic.build(circuit: QuantumCircuit, debug: bool = False) → tuple[QuantumCircuit, Samplex]">
  Build a circuit template and samplex for the given boxed-up circuit.

  <Admonition title="Note" type="note">
    The template circuit does not preserve the `global_phase` of the input circuit, it is always set to zero.
  </Admonition>

  **Parameters**

  *   **circuit** – The circuit to build.
  *   **debug** – Whether to populate samplex nodes with information that traces them back to the boxes that generated them. Tracing information is based on `ref` attributes of box annotations.

  **Returns**

  The built template circuit and the corresponding samplex.
</Function>
