  A node that produces samples for twirling.

  **Parameters**

  *   **lhs\_register\_name** – The name of the register to store the samples.
  *   **rhs\_register\_name** – The name of the register to store the inverses of the samples.
  *   **distribution** – The distribution to draw samples from.
