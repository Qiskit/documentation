# AddTerminalRightDressedBoxes

<Class id="samplomatic.transpiler.passes.AddTerminalRightDressedBoxes" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/transpiler/passes/add_terminal_right_dressed_boxes.py#L69-L208" signature="samplomatic.transpiler.passes.AddTerminalRightDressedBoxes(*args, **kwargs)" modifiers="class">
  Bases: [`TransformationPass`](/docs/api/qiskit/qiskit.transpiler.TransformationPass)

  Add right-dressed boxes to collect uncollected virtual gates emitted by left-dressed boxes.

  <Admonition title="Note" type="note">
    All boxes added by this pass are empty, so consider combining this pass with [`AbsorbSingleQubitGates`](transpiler-passes-absorb-single-qubit-gates "samplomatic.transpiler.passes.AbsorbSingleQubitGates") if you would like nearby single-qubit gates to be placed into the boxes this pass adds.
  </Admonition>

  **Parameters**

  *   **group** – The group to use for the box.
  *   **decomposition** – The decomposition to use for the box.
