  ### generate\_template\_values

  <Function id="samplomatic.synths.Synth.generate_template_values" github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/synths/synth.py#L61-L74" signature="generate_template_values(register: VirtualRegister) → ndarray" modifiers="abstractmethod">

    **Parameters**

    **register** – The data register containing the virtual gates to generate template parameter values for.

    **Returns**

    An array of shape `(register.num_subsystems, register.num_samples, num_params)`.

    **Raises**
