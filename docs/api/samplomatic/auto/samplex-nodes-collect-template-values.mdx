# CollectTemplateValues

<Class id="samplomatic.samplex.nodes.CollectTemplateValues" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/samplex/nodes/collect_template_values.py#L24-L136" signature="samplomatic.samplex.nodes.CollectTemplateValues(template_params_name: str, template_idxs: ndarray[tuple[int, int], dtype[int64]], register_name: str, register_type: VirtualType, subsystem_idxs: ndarray[tuple[int], dtype[int64]], synth: Synth)" modifiers="class">
  Bases: [`CollectionNode`](samplex-nodes-collection-node "samplomatic.samplex.nodes.collection_node.CollectionNode")

  Collects a register slice and writes corresponding template values to output.

  **Parameters**

  *   **template\_params\_name** – The name of the output to write template parameters to.
  *   **template\_idxs** – An array of shape `(num_subsystems, num_params_per_subsystem)` specifying which entries of the entire template parameter value array to write to.
  *   **register\_name** – The name of the register to collect.
  *   **register\_type** – What kind of register type to collect.
  *   **subsystem\_idxs** – The slice of the register to collect.
  *   **synth** – A synth to take the product of register values and generate template parameter values.

  **Raises**

  *   [**SamplexConstructionError**](exceptions-samplex-construction-error "samplomatic.exceptions.SamplexConstructionError") – If `register_type` is not compatible with `synth`.
  *   [**SamplexConstructionError**](exceptions-samplex-construction-error "samplomatic.exceptions.SamplexConstructionError") – If the second axis of `template_idxs` does not match [`Synth.num_params`](synths-synth#num_params "samplomatic.synths.Synth.num_params"), or the first axis of `template_idxs` does not match the number of subsystems in each entry of `registers`.
