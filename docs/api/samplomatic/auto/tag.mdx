# samplomatic.Tag

<Class id="samplomatic.Tag" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/annotations/tag.py#L18-L49" signature="samplomatic.Tag(ref: str = '')" modifiers="class">
  Annotation to tag and instruction with a string reference.

  When present on a `box` instruction, the barriers emitted during [`build()`](build "samplomatic.build") include the `ref` of this annotation as part of their label information. In this way, when combined with the build function, a tag annotation can be used as a tracing mechanism to tie a “barrier sandwich” in a template circuit back to the box it came from in the original circuit.

  **Parameters**

  **ref** – A reference string.
