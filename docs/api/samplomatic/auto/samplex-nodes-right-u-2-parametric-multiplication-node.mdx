# RightU2ParametricMultiplicationNode

<Class id="samplomatic.samplex.nodes.RightU2ParametricMultiplicationNode" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/samplex/nodes/u2_param_multiplication_node.py#L139-L179" signature="samplomatic.samplex.nodes.RightU2ParametricMultiplicationNode(operand: Literal['rz', 'rx'], register_name: str, param_idxs: list[int])" modifiers="class">
  Bases: [`U2ParametricMultiplicationNode`](samplex-nodes-u-2-parametric-multiplication-node "samplomatic.samplex.nodes.u2_param_multiplication_node.U2ParametricMultiplicationNode")

  Perform parametric right multiplication on a [`U2Register`](virtual-registers-u-2-register "samplomatic.virtual_registers.U2Register").

  The node stores a parametric representation $g$ of a one-qubit gate or gates from the original circuit and performs a $reg*g$ multiplication, where $reg$ is the existing `U2Register`.

  $g$ is limited to the gates `rz` or `rx`, and all gates within the node are of the same type.

  **Parameters**

  *   **operand** – The gate type, given as a string.
  *   **register\_name** – The name of the register the operation is applied to.
  *   **param\_idxs** – List of `ParamIndex` for the parameter expressions specifying the gate arguments. List order must match the order subsystems in the registry.

  **Raises**

  [**SamplexConstructionError**](exceptions-samplex-construction-error "samplomatic.exceptions.SamplexConstructionError") – if param\_idxs is empty.
