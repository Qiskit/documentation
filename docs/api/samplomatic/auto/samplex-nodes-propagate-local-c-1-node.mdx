# PropagateLocalC1Node

<Class id="samplomatic.samplex.nodes.PropagateLocalC1Node" isDedicatedPage={true} github="https://github.com/Qiskit/samplomatic/tree/main/samplomatic/samplomatic/samplex/nodes/propagate_local_c1_node.py#L29-L111" signature="samplomatic.samplex.nodes.PropagateLocalC1Node(op_name: str, register_name: str, subsystem_idxs: Sequence[Sequence[int]], *, lookup_table: ndarray | None = None)" modifiers="class">
  Bases: [`EvaluationNode`](samplex-nodes-evaluation-node "samplomatic.samplex.nodes.evaluation_node.EvaluationNode")

  A node that propagates a C1 register past a gate.

  **Parameters**

  *   **op\_name** – The name of the gate.
  *   **register\_name** – The name of the C1 register to propagate.
  *   **subsystem\_idxs** – The subsystems in the register. The expected format is that of a collection of subsystems of the same size, i.e., that of a 2D array where the left-most axes is over subsystems and the right-most axes is over qubits.
