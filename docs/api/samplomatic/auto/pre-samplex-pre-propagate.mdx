  ### commutant\_twirl

  <Attribute id="samplomatic.pre_samplex.PrePropagate.commutant_twirl">
    Type: [`bool`](https://docs.python.org/3/builtins/functions.html#bool)

    Default value: `False`

    Whether this operation should be twirled with its commutant.

    If the operation is not a fractional gate, this value will be `False`. If it is a fractional gate, `True` signals that it should be twirled by its commutant, while `False` signals that its angle has been bound to a Clifford.
  </Attribute>
