# CustomF2QLayout

<Class id="qiskit_fermions.transpiler.passes.CustomF2QLayout" isDedicatedPage={true} signature="CustomF2QLayout(layout)" modifiers="class">
  Bases: [`GenericPass`](/docs/api/qiskit/qiskit.passmanager.GenericPass)\[[`DAGCircuit`](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit), [`DAGCircuit`](/docs/api/qiskit/qiskit.dagcircuit.DAGCircuit)]

  Sets the user-provided [`F2QLayout`](qiskit-fermions-transpiler-f-2-q-layout "qiskit_fermions.transpiler.F2QLayout") in the transpiler.

  This pass simply populates the `f2q_layout` field of the [`property_set`](/docs/api/qiskit/qiskit.passmanager.PassManagerState#property_set), with the value of [`layout`](#qiskit_fermions.transpiler.passes.CustomF2QLayout.layout "qiskit_fermions.transpiler.passes.CustomF2QLayout.layout").

  <Admonition title="Note" type="note">
    It is the user’s responsibility to ensure that subsequently used transpilation passes (and plugins) are configured to adhere to this [`F2QLayout`](qiskit-fermions-transpiler-f-2-q-layout "qiskit_fermions.transpiler.F2QLayout") correctly.
  </Admonition>

  Initializing this transpiler pass can be done with the arguments listed below.

  **Parameters**

  **layout** ([*F2QLayout*](qiskit-fermions-transpiler-f-2-q-layout "qiskit_fermions.transpiler.F2QLayout")) – the custom `f2q_layout` to use.
