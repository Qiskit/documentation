# qiskit\_noise\_learning.analysis.SymmetrizeFidelities

<Class id="qiskit_noise_learning.analysis.SymmetrizeFidelities" isDedicatedPage={true} github="https://github.com/Qiskit/qiskit-noise-learning/tree/stable/0.1/qiskit_noise_learning/analysis/symmetrize.py" signature="qiskit_noise_learning.analysis.SymmetrizeFidelities" modifiers="class">
  Bases: [`AnalysisStage`](analysis-analysis-stage "qiskit_noise_learning.analysis.analysis_pipeline.AnalysisStage")

  Project generator rates into the fidelity-symmetry null space, gate by gate.

  For each gate, builds commutation matrices of generators against generators and conjugated generators against generators, then projects rates into the null space of their difference. Covariance is zeroed (the iterative projection with clipping is non-linear).
