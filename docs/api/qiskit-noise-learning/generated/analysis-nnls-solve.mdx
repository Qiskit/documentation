# qiskit\_noise\_learning.analysis.NNLSSolve

<Class id="qiskit_noise_learning.analysis.NNLSSolve" isDedicatedPage={true} github="https://github.com/Qiskit/qiskit-noise-learning/tree/stable/0.1/qiskit_noise_learning/analysis/model_solve.py" signature="qiskit_noise_learning.analysis.NNLSSolve(**nnls_opts)" modifiers="class">
  Bases: `ModelSolve`

  Solves for the [`ModelData`](data-model-data "qiskit_noise_learning.data.ModelData") using SciPy’s non-negative least squares solver.

  See SciPy’s [documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.nnls.html) for details on the method. See `ModelSolve` for more details about the general responsibility of a model solver in this library.

  **Parameters**

  **\*\*nnls\_opts** – The options passed on to the SciPy solver.
