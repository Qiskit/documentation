# qiskit\_noise\_learning.analysis.ComputeObservables

<Class id="qiskit_noise_learning.analysis.ComputeObservables" isDedicatedPage={true} github="https://github.com/Qiskit/qiskit-noise-learning/tree/stable/0.1/qiskit_noise_learning/analysis/compute_observables.py" signature="qiskit_noise_learning.analysis.ComputeObservables" modifiers="class">
  Bases: [`AnalysisStage`](analysis-analysis-stage "qiskit_noise_learning.analysis.analysis_pipeline.AnalysisStage")

  Compute observable data from raw data.

  This analysis stage utilizes existing relations between paths and instruction sequences in the [`Fit`](analysis-fit "qiskit_noise_learning.analysis.Fit") to determine how to compute observables. If relations are not specified, they are greedily constructed by exhaustively comparing paths in `fit.paths` and the instruction sequences in `fit.raw_data`. Note that in this latter case, `fit.paths` is not updated and will therefore remain `None`.
