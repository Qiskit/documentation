  Generate depth-0 paths.

  **Parameters**

  *   **prep\_gate** – The preparation gate. If `None`, defaults to the gate named `"P"`.
  *   **meas\_gate** – The measurement gate. If `None`, defaults to the gate named `"M"`.
  *   **indices\_list** – An iterable of qubit index lists. If `None`, generates single-qubit paths for every qubit.
