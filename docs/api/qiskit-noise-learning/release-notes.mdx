<span id="release-notes-0-2-0" />

## 0.2.0

<span id="release-notes-0-2-0-new-features" />

### New Features

*   Added the [`build_with_prep_noise()`](/docs/api/qiskit-noise-learning/generated/utils-build-with-prep-noise#qiskit_noise_learning.utils.build_with_prep_noise "qiskit_noise_learning.utils.build_with_prep_noise") utility function to allow injection of preparation noise.

*   Extends the [`suffix_creg_identifier()`](/docs/api/qiskit-noise-learning/generated/analysis-suffix-creg-identifier#qiskit_noise_learning.analysis.suffix_creg_identifier "qiskit_noise_learning.analysis.suffix_creg_identifier") to accept a list of suffixes rather than just one.

<span id="release-notes-0-2-0-bug-fixes" />

### Bug Fixes

*   Fixed [`clifford_propagate()`](/docs/api/qiskit-noise-learning/generated/gate-sets-model-gate#qiskit_noise_learning.gate_sets.ModelGate.clifford_propagate "qiskit_noise_learning.gate_sets.ModelGate.clifford_propagate") with `inverse=True`; it was traversing the cliffords in forward temporal order regardless of whether `inverse==True` or `inverse==False`.
