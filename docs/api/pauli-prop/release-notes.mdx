# Pauli propagation release notes

<span id="release-notes-0-2-0" />

<span id="id2" />

## 0.2.0

<span id="release-notes-0-2-0-new-features" />

### New Features

*   The [`pauli_prop.propagation`](/docs/api/pauli-prop/propagation#module-pauli_prop.propagation "pauli_prop.propagation") module now supports propagation of noisy circuits.

    *   `propagate_through_circuit()` accepts circuits containing `PauliLindbladError` instructions from Qiskit Aer.
    *   `propagate_through_rotation_gates()` now accepts either `RotationGates` or `NoisyRotationGates` instances.
